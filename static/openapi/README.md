# OpenAPI specs

Rendered by Scalar on `/api/reference/<id>` (src/components/ApiReference). The browser fetches these files, so a newer export can simply replace them.

| File | Export from |
|------|-------------|
| `tsflux.yaml` | A running tsflux: `/tsflux/swagger/doc.json` (Scalar reads JSON or YAML, so the JSON export can be saved as is) |
| `ocb.yaml` | A running OCB: the `/api/v2` document |
| `nbq.yaml` | The NBQ repo, `apps/nbq/docs/openapi.yaml` (hand-edited, also served at `/openapi.yaml` by a running nbq) |
