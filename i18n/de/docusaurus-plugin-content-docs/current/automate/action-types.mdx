Jeder Ort, der Aktionen ausführt, bietet eine andere Liste. Zuerst kommt die Liste je Ort, dann die Felder jedes Typs.

## Welcher Ort welchen Typ bietet {#which-place-offers-which-type}

| Ort | Aktionstypen | Läuft |
| --- | --- | --- |
| **Regel**, Knoten **Aktionen** | **Benachrichtigung**, **Benachrichtigungskanal**, **E-Mail**, **Webhook**, **Ereignis**, **Telemetrien aktualisieren** | Wenn der Auslöser der Regel feuert |
| **Event-Typ**, Tab **Aktionen** | **Benachrichtigung**, **Benachrichtigungskanal**, **E-Mail**, **Webhook** | Wenn ein Event dieses Typs entsteht, außer bei Events, die eine Episode beenden. Eine neue Aktion startet ausgeschaltet: Schalten Sie **Aktiv** ein. |
| **Thing-Typ** oder **Thing**, Tab **Aktionen** | **Webhook**, **Azure C2D**, **MQTT** | Wenn eine Person, ein Dashboard oder die API sie auslöst |

**Telemetrien aktualisieren** gibt es nur, wenn der Knoten **Start** der Regel **Thing-Typ** verwendet. Der Schweregrad ist **Information**, **Warnung**, **Fehler** oder **Kritisch**.

## Benachrichtigung {#notification}

Eine In-App-Benachrichtigung an Benutzer und Gruppen. Wird in Regeln und bei Event-Typen verwendet.

| Feld | Bedeutung |
| --- | --- |
| **Betreff** | Pflicht. |
| **Schweregrad** | Pflicht. |
| **Nachricht** | Pflicht. |
| **Benutzer und Gruppen** | Mindestens ein Benutzer oder eine Gruppe. |

## Benachrichtigungskanal {#notification-channel}

Eine Nachricht an einen oder mehrere [Benachrichtigungskanäle](../watch/alert-channels.mdx) wie Slack, Teams, einen Webhook-Empfänger oder ntfy. Wird in Regeln und bei Event-Typen verwendet.

| Feld | Bedeutung |
| --- | --- |
| **Benachrichtigungskanal** | Pflicht. Wählen Sie einen oder mehrere. Ein ausgeschalteter Kanal ist in der Liste markiert. |
| **Betreff**, **Nachricht**, **Schweregrad** | Optional. |

## E-Mail {#email}

Eine E-Mail an Benutzer, Gruppen oder externe Adressen. Wird in Regeln und bei Event-Typen verwendet. E-Mails gehen über den Mailserver des Tenants, falls einer eingerichtet ist, sonst über den Mailserver der Plattform.

| Feld | Bedeutung |
| --- | --- |
| Format | **Plain** oder **Mail-Vorlage**. |
| **Betreff**, **Inhalt** | Pflicht bei **Plain**. |
| **Mail-Vorlage** | Pflicht bei **Mail-Vorlage**. Siehe [E-Mail-Vorlagen und Platzhalter](../watch/mail-templates.mdx). |
| **Absender**, **Cc**, **Bcc** | Optional. |
| Empfänger | Mindestens ein Benutzer, eine Gruppe oder eine externe Adresse. |

**Betreff** und **Inhalt** akzeptieren Platzhalter in doppelten geschweiften Klammern. Platzhalter gelten nicht, wenn Sie eine Mail-Vorlage wählen.

## Webhook {#webhook}

Eine HTTP-Anfrage an ein anderes System. Wird in Regeln und bei Event-Typen verwendet, und als Thing-Aktion.

| Feld | Bedeutung |
| --- | --- |
| **Method** | `GET`, `POST`, `PUT`, `PATCH` oder `DELETE`. |
| **URL** | Die Adresse, die aufgerufen wird. |
| **Inhalt** | Pflicht bei `POST`, `PUT` und `PATCH`. |
| **Headers** | Paare aus Schlüssel und Wert. Schlüssel müssen eindeutig sein, und ein Schlüssel braucht einen Wert. |
| **Autorisierungstyp** | Siehe die nächste Tabelle. |

| Autorisierungstyp | Felder |
| --- | --- |
| **Keine** | keine |
| **Bearer** | **Token** |
| **Basic** | **Benutzername**, **Passwort** |
| **Abfrage** | **Abfrageparameter-Schlüssel**, **Abfrageparameter-Wert**, an die URL angehängt |
| **OAuth2** | **Token Endpunkt**, **Berechtigungstyp**, optional **Umfang**, und Felder, die vom Berechtigungstyp abhängen |

OAuth2-Berechtigungstypen: **Client-Anmeldeinformationen** (**Client-ID**, **Client-Geheimnis**), **Passwort** (**Benutzername**, **Passwort**), **Aktualisierungs-Token** (**Aktualisierungs-Token**) und **JWT (JSON Web Token)** (**JWT assertion**).

## Ereignis {#event}

Erzeugt ein Event. Nur in Regeln.

| Feld | Bedeutung |
| --- | --- |
| **Titel** | Pflicht. Der Titel des Events. |
| **Event Typ** | Pflicht. Das Event erscheint unter **Überwachung › Events** und führt die Aktionen dieses Event-Typs aus. |
| **Schweregrad** | Pflicht. |

## Telemetrien aktualisieren {#update-measures}

Schreibt Werte in Messwerte des Thing-Typs. Nur in Regeln, und nur mit einem Knoten **Start**, der auf **Thing-Typ** steht. Sie geben ein JSON-Objekt ein, das Messwertnamen auf Werte abbildet. Die Messwerte müssen am Thing-Typ existieren.

## MQTT {#mqtt}

Ein Befehl, der an ein Gerät veröffentlicht wird. Nur Thing-Aktionen. Funktioniert für Geräte, die mit dem Konnektor **Nimbit** verbunden sind.

| Feld | Bedeutung |
| --- | --- |
| **Name** | Wird in Listen und auf Dashboards angezeigt. |
| **Unterthema** | Optional. Wird an `iot/tenant/<tenant>/device/<device>/cmd/` angehängt. Höchstens 128 Zeichen, 8 Ebenen und 64 Zeichen pro Ebene. Buchstaben, Ziffern, `_` und `-`, getrennt durch `/`. Platzhalter erlaubt. |
| **Payload-Format** | **JSON** oder **Text**. Bei **JSON** muss das Ergebnis nach dem Einsetzen gültiges JSON sein, und eine Payload ist Pflicht. |
| **Payload** | Die Nachricht, bis zu 64 KiB. |

Platzhalter sind einfache Werte in doppelten geschweiften Klammern: `{{thing.id}}`, `{{thing.name}}`, `{{thing.alternateId}}`, `{{messageId}}` und Messwerte des Thing-Typs über **Platzhalter einfügen**. Sections, Partials und Wechsel der Trennzeichen werden abgelehnt. Der Befehl wird höchstens einmal zugestellt, nur an ein verbundenes Gerät. Siehe [Einen Befehl an ein Gerät senden](./device-command.mdx).

## Azure C2D {#azure-c2d}

Eine Cloud-to-Device-Nachricht, gesendet auf dem Topic `/devicebound`. Nur Thing-Aktionen. Für Things, die mit dem Anbietertyp Azure registriert sind.

| Feld | Bedeutung |
| --- | --- |
| **Name**, **Beschreibung** | Der Name wird in Listen angezeigt. |
| **Dies ist eine Umschaltaktion (EIN/AUS).** | Macht daraus eine Ein/Aus-Aktion. |
| **Payload** | Die Nachricht. Bei einer Umschaltaktion heißt sie **Daten für "An"**. Platzhalter werden ersetzt, wenn der Befehl gesendet wird. |
| **Daten für "Aus"** | Die Nachricht für Aus. Nur Umschaltaktionen. |

Auf einer Thing-Seite zeigt eine Umschaltaktion **Einschalten** oder **Ausschalten** und den Zustand aus dem letzten Messwert des Things. Nur Azure C2D bietet diese Option. MQTT kennt keinen Umschalter.

## Felder jeder Thing-Aktion {#fields-on-every-thing-action}

| Feld | Bedeutung |
| --- | --- |
| **Verwendung als Dashboard-Widget zulassen** | Lässt ein Widget **Aktion** sie auslösen. Jeder, der das Dashboard öffnen kann, kann die Aktion auslösen. |
| **Aktiv** | Ein Schalter in der Aktionsliste des Thing-Typs. Eine inaktive Aktion lässt sich nicht auslösen. Webhook-Aktionen werden inaktiv angelegt. MQTT- und Azure-C2D-Aktionen werden aktiv angelegt. |
| **Geerbt** | Kennzeichnet bei einem Thing eine Aktion, die an seinem Thing-Typ definiert ist. Ändern Sie sie dort. |

Öffnen Sie **Protokoll** im Tab **Aktionen**, um jeden Lauf zu sehen, mit **Wann**, Status und Herkunft.
