Felder eines Berichts unter **Automatisierung › Berichte** und wie sein Zeitplan und seine Zustellung funktionieren.

## Bericht {#report}

| Feld | Bedeutung |
| --- | --- |
| **Name** | Pflicht. Im Tenant eindeutig. |
| **Beschreibung** | Optional. |
| **Dateiname** | Pflicht. Der Name des erzeugten PDFs. Drücken Sie `@`, um einen Wert aus der nächsten Tabelle einzufügen. |
| **Ordner** | Pflicht. Wo das PDF gespeichert wird. Sie finden es im Datei-Explorer. |
| **Things** | Pflicht. Mindestens ein Thing. |
| **Benutzer**, **Gruppen** | Wer den Bericht öffnen kann. Wählen Sie keine aus, kann es jeder im Tenant. |
| **Tags** | Optionale Labels, um den Bericht in der Liste zu finden. Sie ändern sonst nichts. |

### Werte für den Dateinamen {#file-name-values}

Werte werden ersetzt, wenn das PDF erstellt wird, in Zeitzone und Sprache des Tenants.

| Wert | Ergebnis |
| --- | --- |
| `{{date}}` | `YYYY-MM-DD` |
| `{{year}}`, `{{month}}`, `{{day}}` | `YYYY`, `MM`, `DD` |
| `{{month_long}}`, `{{month_short}}` | Der ausgeschriebene oder kurze Monatsname |
| `{{date_time}}` | Datum und Uhrzeit ohne Doppelpunkte, zum Beispiel `2026-06-15_22-34-56` |
| `{{timestamp}}` | Unix-Zeit in Sekunden |
| `{{tenant}}` | Der Tenant |
| `{{uuid}}` | Eine eindeutige ID |

## Zeitplan {#schedule}

| Feld | Bedeutung |
| --- | --- |
| **Startdatum**, **Startzeit** | Wann der erste Bericht erzeugt wird. Standardmäßig der Moment, in dem Sie das Formular öffnen. |
| **Zeitfenster** | Der Zeitraum, den jeder Bericht abdeckt, als Bereich relativ zur Laufzeit. Standardmäßig **Letzte 7 Tage**. Sie können auch die Zeitzone festlegen, in der der Bereich aufgelöst wird. |
| **Wiederhole jeden** | Eine Zahl und eine Einheit: **Stunde**, **Tag**, **Woche**, **Monat** oder **Jahr**. Standardmäßig 1 **Tag**. |

Ein geplanter Lauf löst das **Zeitfenster** in dem Moment auf, in dem er feuert. Der Zeitplan läuft nur, solange der Bericht veröffentlicht ist. Das Zeitplansymbol der Liste zeigt den letzten und den nächsten Lauf.

## Veröffentlichen {#publish}

| Zustand | Bedeutung |
| --- | --- |
| Nicht veröffentlicht | Kein Zeitplan läuft. Neue und kopierte Berichte beginnen hier. |
| Veröffentlicht | Der Zeitplan läuft ab Startdatum und Startzeit. Die Schaltfläche im Kopfbereich lautet **Veröffentlichung aufheben**. |

Das Veröffentlichen wird abgelehnt, wenn **Startdatum**, **Startzeit** oder **Wiederhole jeden** fehlt: „Der Bericht kann nicht veröffentlicht werden, da der Zeitraum nicht vollständig definiert ist.“

## Abonnements {#subscriptions}

Öffnen Sie **Abonnements** im Kopfbereich des Editors. Jeder Abonnent erhält jeden erzeugten Bericht.

| Option | Bedeutung |
| --- | --- |
| **Nutzer hinzufügen** | Einen Benutzer des Tenants abonnieren. |
| **Extern** | Eine E-Mail-Adresse ohne Konto abonnieren. Externe Abonnenten erhalten nur E-Mails. |
| **E-Mail** | Das PDF per E-Mail senden. Braucht einen Mailserver für den Tenant. Die E-Mail hat einen Link zum Abbestellen. |
| **Benachrichtigung** | Eine In-App-Benachrichtigung senden, mit dem Titel „Bericht `<name>` generiert“. |

Ohne Mailserver warnt die App: „Kein Mailserver konfiguriert. Abonnements werden nicht als E-Mail versendet.“

## Generieren {#generate}

**Generieren** im Kopfbereich des Editors öffnet ein Popover mit einem Zeitraum.

| Option | Bedeutung |
| --- | --- |
| Zeitraum | Ein relativer oder absoluter Bereich. Standardmäßig das **Zeitfenster** des Berichts. |
| **Zeitverschiebung** | Verschiebt den Bereich in die Vergangenheit, zum Beispiel `-6h` oder `-3d`. Gilt nur für relative Bereiche. |
| **Herunterladen** | Öffnet den Druckdialog des Browsers für den Bericht. Wählen Sie **Als PDF speichern**. Nichts wird gespeichert oder gesendet. |
| **Erstellen und senden** | Erzeugt das PDF, speichert es im **Ordner** und sendet es an die Abonnenten. Die Schaltfläche ist danach 30 Sekunden deaktiviert. Das PDF erscheint nach etwa 30 Sekunden. |

## Editor {#editor}

| Bedienelement | Bedeutung |
| --- | --- |
| Stift | Wechselt in den Bearbeitungsmodus oder verlässt ihn. Beim Verlassen wird gespeichert. Der Kopfbereich zeigt **Gespeichert** oder **Ungespeicherte Änderungen**. |
| **Seite hinzufügen** | Fügt eine Seite hinzu. Löschen Sie eine Seite mit Widgets, werden die Widgets gelöscht. |
| **Canvas-Größe** | **A4 Hochformat**, **A4 Querformat** oder **Benutzerdefiniert**. |
| **In den Vordergrund**, **In den Hintergrund** | Reihenfolge überlappender Widgets, im Menü eines Widgets. |
| **Vorschau** | Öffnet den Bericht in einem neuen Tab. |
| Zahnrad | Öffnet die Berichtseinstellungen: die Felder oben. |

## Berichtsliste {#report-list}

| Spalte | Bedeutung |
| --- | --- |
| **Name** | Öffnet den Editor. |
| **Status** | Veröffentlicht oder nicht. |
| **Veröffentlicht am** | Wann er zuletzt veröffentlicht wurde. |
| **Zeitplan** | Letzter und nächster Lauf. |
| **Gruppen**, **Benutzer**, **Things** | Wer ihn sieht und was er abdeckt. |
| **Tags** | Ihre Labels. |

Jede Zeile hat **Bericht kopieren** und **Vorschau**. Eine Kopie ist nie veröffentlicht. Um Berichte zu löschen, setzen Sie Häkchen und nutzen Sie die Löschaktion in der Symbolleiste. Ein Dialog **Bericht löschen** bittet um Bestätigung.
