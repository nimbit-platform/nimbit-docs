Verhindern Sie, dass ein Gateway sendet, übergeben Sie seine Identität an eine neue Box oder löschen Sie es. Wie sich ein Gateway anmeldet, steht unter [Wie Gateways funktionieren](./how-gateways-work.mdx).

## Voraussetzungen {#before-you-start}

- Um einen Schlüssel zu widerrufen oder einen neuen Code oder neue Zugangsdaten auszustellen, brauchen Sie die Berechtigung zum Ändern von Gateways. Um ein Gateway zu löschen, brauchen Sie die Berechtigung zum Löschen.
- Kennen Sie den Typ des Gateways. Ein **Periscope**-Gateway hat Schlüssel und Onboarding-Codes. Ein Gateway vom Typ **MQTT-Gerät** hat einen Satz Zugangsdaten.

## Wie schnell es wirkt {#how-fast-it-takes-effect}

| Was | Wann es endet |
| --- | --- |
| Eine neue MQTT-Anmeldung mit den alten Zugangsdaten | Sofort. Die Plattform merkt sich eine erfolgreiche Prüfung unter Umständen einige Sekunden lang. |
| Eine MQTT-Sitzung, die schon offen ist | Innerhalb von 10 Minuten. Jede Gateway-Sitzung endet nach höchstens 10 Minuten. |
| HTTP- und Stream-Schreibzugriffe einer Periscope-Box | Wenn ihr aktuelles Token abläuft, nach höchstens 10 Minuten. Sie erhält kein neues Token. |
| Eine Periscope-Anmeldung mit einem widerrufenen Schlüssel | Sofort. Ein Anmelde-Token, das der Schlüssel schon erhalten hat, gilt höchstens 5 Minuten. |

## Einen Periscope-Schlüssel widerrufen {#revoke-a-periscope-key}

1. Öffnen Sie das Gateway und wählen Sie den Tab **Zugriff & Schlüssel**.
2. Suchen Sie unter **Schlüssel** den Schlüssel und wählen Sie **Schlüssel widerrufen**, dann **Widerrufen**.

Die Box kann sich mit diesem Schlüssel nicht mehr anmelden. War es der letzte Schlüssel des Gateways, wird das Gateway **Nicht registriert**. Es erhält dann gar keine Zugangsdaten mehr, bis sich eine Box mit einem neuen Onboarding-Code wieder registriert. Bleiben andere Schlüssel, bleibt das Gateway, wie es ist, und seine Box fragt bei der nächsten Anmeldung nach neuen Zugangsdaten.

## Eine Periscope-Box ersetzen {#replace-a-periscope-box}

1. Um die alte Box sofort auszusperren, widerrufen Sie zuerst ihren Schlüssel, wie oben.
2. Öffnen Sie das Zeilenmenü des Gateways und wählen Sie **Neuer Onboarding-Code**, dann **Code ausstellen**. Wählen Sie, wie lange der Code gültig ist.
3. Kopieren Sie den Code. Der frühere Code verliert sofort seine Gültigkeit, auch wenn ihn niemand eingelöst hat.
4. Registrieren Sie die neue Box: `periscope enroll -code ONB-XXXX-XXXX-XXXX-XXXX`, oder fügen Sie den Code in die Einrichtungsseite ein. Siehe [Gateway hinzufügen](./add-a-gateway.mdx).

Die Registrierung ersetzt jeden Schlüssel des Gateways. Das Gateway behält seinen Namen, seinen Namespace, seinen Scope und seine Things, und die neue Box findet ihre Things über ihre Alternate-IDs wieder. Bis sich eine Box mit dem neuen Code registriert, funktionieren die alten Schlüssel weiter. Widerrufen Sie den alten Schlüssel also zuerst, wenn Sie ihn sperren müssen.

## Ein MQTT-Gerät ersetzen {#replace-an-mqtt-device}

1. Öffnen Sie das Zeilenmenü des Gateways und wählen Sie **Neue Zugangsdaten**, dann **Zugangsdaten ausstellen**.
2. Kopieren Sie das **Passwort** oder wählen Sie **Konfiguration herunterladen**. IoT Breeze zeigt es einmal an.
3. Übertragen Sie die neuen Zugangsdaten auf das Gerät oder auf sein Ersatzgerät.

Anmeldungen mit dem alten Passwort werden sofort abgelehnt. Eine Verbindung, die schon offen ist, endet innerhalb von 10 Minuten. Das Gateway behält seine Things. Betreiben Sie das alte und das neue Gerät nicht mit derselben Client-ID: Zwei Verbindungen mit einer Client-ID verdrängen sich gegenseitig. Geben Sie jedem ein eigenes `:<suffix>`, um sie nebeneinander zu betreiben.

## Ein Gateway entfernen {#remove-a-gateway}

1. Öffnen Sie das Zeilenmenü des Gateways und wählen Sie **Gateway löschen**.
2. Bestätigen Sie.

IoT Breeze löscht:

- den Gateway-Eintrag und damit seine Schlüssel und einen ausstehenden Onboarding-Code oder seine MQTT-Zugangsdaten;
- das Gateway-Thing, `gateway-<gateway id>`.

Die Things, die das Gateway angelegt oder zugeordnet bekommen hat, bleiben. Sie gehören zu keinem Gateway mehr, eine Nachricht für eines über den Pfad des Gateways würde also verworfen. Geben Sie sie frei oder ordnen Sie sie neu zu, wie Sie es brauchen; siehe [Die Things hinter einem Gateway verwalten](./things-behind-a-gateway.mdx). Die ID des Gateways wird nie wiederverwendet.

Die Box kann sich nicht mehr anmelden. Offene MQTT-Sitzungen enden innerhalb von 10 Minuten. Um ein Gateway auf neue Hardware umzuziehen und seine Things zu behalten, stellen Sie stattdessen einen neuen Onboarding-Code aus, statt es zu löschen.

Lässt sich das Gateway-Thing nicht zusammen mit dem Gateway löschen, ist das Gateway weg, und `gateway-<gateway id>` bleibt als gewöhnliches Thing. Löschen Sie es von Hand.

## Alle MQTT-Gateway-Zugangsdaten auf einmal beenden {#end-every-mqtt-gateway-credential-at-once}

Das Rotieren des Signaturschlüssels des Tenants beendet die Zugangsdaten, die mit dem rotierten Schlüssel signiert wurden. MQTT-Geräte-Gateways verwenden den Schlüssel **Primär**. Nach der Rotation braucht jedes MQTT-Gateway **Neue Zugangsdaten**. Dieselbe Rotation sperrt auch alle Gerätezugangsdaten dieses Schlüssels. Tun Sie das nur, wenn sich alle ändern müssen; siehe [Gerätezugangsdaten anlegen und rotieren](../connect/credentials.mdx).

## Prüfen, ob es geklappt hat {#check-that-it-worked}

Der Status des Gateways ändert sich in der Liste: **Nicht registriert**, nachdem der letzte Schlüssel widerrufen ist, **Wartet auf Onboarding** nach einem neuen Code, **Online**, sobald die neue Box oder das neue Gerät seinen Zustand sendet. Nach dem Löschen ist das Gateway aus der Liste verschwunden.

## Wenn es nicht klappt {#if-it-doesnt-work}

- **Die alte Box sendet nach einem Widerruf noch**: Warten Sie bis zu 10 Minuten, bis ihre MQTT-Sitzung oder ihr HTTP-Token endet.
- **Der Code wird abgelehnt**: Ein Code funktioniert einmal und bis zu seinem Ablauf. Stellen Sie einen neuen aus.
- **Neue Zugangsdaten werden abgelehnt**: Das Gerät hält noch das alte Passwort oder eine Konfigurationsdatei, die später heruntergeladen wurde und einen Platzhalter statt des Passworts enthält. Laden Sie das Passwort oder die Datei aus dem Ergebnis von **Neue Zugangsdaten**. Verloren? Stellen Sie neue Zugangsdaten aus.
