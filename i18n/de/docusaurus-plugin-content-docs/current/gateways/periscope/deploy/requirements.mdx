What a box needs before you install Periscope on it. Nothing has to reach the box except the people who open its web UI.

## System

| Item | Requirement |
| --- | --- |
| Operating system | Linux. Periscope is one static binary with no other dependency. Other operating systems are not supported. |
| Architectures | The binary is built for `linux/amd64`, `linux/arm64` and 32-bit ARM (ARMv7). `uname -m` prints `x86_64`, `aarch64` or `armv7l`. |

## Disk for queues

While the platform is unreachable, each platform output keeps values on disk and sends them when the link returns. Without enough free disk, the oldest values are dropped and counted.

| Output | Queue | Bytes per value |
| --- | --- | --- |
| `tsflux_stream` | `state_dir/tsflux-stream/<output>/` | about 9 |
| `tsflux`, `nimbit_mqtt` | `state_dir/spool/<output>/` | about 15 |

The default bound is 256 MiB per output. At start, the output lowers it to half of its share of the free space. To ride out an outage of a given length, plan for the outage in seconds times values per second times the bytes per value, and leave twice that much free. The table of outage lengths is in the [Outputs reference](../outputs.mdx).

## Network

Periscope opens every connection itself, so the firewall needs outbound rules only. The platform's address is `[ocb] url`.

| To | Port and protocol | Used for | Needed |
| --- | --- | --- | --- |
| The platform's host | 443, HTTPS | Onboarding and sign-in at the identity directory, the platform backend (apply, the gateway's record, credentials), the `tsflux` HTTP output, and `periscope verify` | Always |
| The platform's host | 8301, HTTP/2 with TLS (gRPC) | The `tsflux_stream` output | With that output |
| The MQTT broker | 8883 (`mqtts://`) or 1883 (`mqtt://`) | The `nimbit_mqtt` output. The broker address comes from the platform unless you set `broker`. | With that output |
| Your sources | Their own ports | OPC UA, Modbus, S7, MQTT and HTTP sources, as on each source page | Always |

A port in `[ocb] url` replaces 443. If the identity directory's token API is not routed through the platform's host, `[auth] url` names another address. Plain `http://`, `mqtt://` and `h2c://` to a host that is not loopback are refused unless the setting `allow_insecure` is `true`.

The web UI and the HTTP API listen on `127.0.0.1:8400`, and in the container image on `0.0.0.0:8400`. Only people who open the UI need to reach that port. Before you open it to the network, set `server.token` or `[server.auth]`.

## Clock

Keep the box's clock right. Sign-in assertions and tokens carry times, and Periscope's health message reports `clock_offset_ms`, the platform's clock minus the box's, measured with the `tsflux` output only. Source values are sent in UTC. A box without a battery-backed clock needs time synchronization at boot. {/* TODO(product): how much clock skew does the platform tolerate before sign-in fails? */}
