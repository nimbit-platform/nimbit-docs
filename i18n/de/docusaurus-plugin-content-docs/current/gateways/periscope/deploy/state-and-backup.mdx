Alles, was Periscope aufbewahrt, liegt in seinem State-Verzeichnis, `agent.state_dir`, standardmäßig `/var/lib/periscope`. Das Verzeichnis wird mit dem Modus 0700 angelegt und seine Dateien mit dem Modus 0600. Die vollständige Liste der Dateien steht in der [Konfigurationsreferenz](../configuration.mdx#state-directory); diese Seite behandelt, was für ein Gateway zählt.

## Identität des Gateways {#identity-of-the-gateway}

| Datei | Enthält | Bei Verlust |
| --- | --- | --- |
| `gateway_key.pem` | Der private Schlüssel der Box. Er verlässt die Box nie. | Die Box kann sich nicht anmelden. Richten Sie sie mit einem neuen Code erneut ein. |
| `gateway_key.next.pem` | Der nächste Schlüssel, solange eine Rotation läuft. Die Box registriert einen neuen Schlüssel 30 Tage, bevor der aktuelle abläuft, und der aktuelle funktioniert danach noch eine Woche. | Nichts, außer eine Rotation lief. |
| `gateway.json` | Die IDs des Gateways, der Ablauf des Schlüssels, die Endpunkte, an denen es sich anmeldet, und die Antwort von `gateways.me` der Plattform: Namespace, Gateway-Thing und sein Thing-Typ. | Der Agent kann sich nicht als Gateway anmelden. Richten Sie die Box erneut ein. |
| `tenant.json` | Die Organisation, zu der dieser State gehört. Der State kann sich nur wieder mit derselben Organisation verbinden. | Die Bindung wird beim nächsten Onboarding neu erstellt. |
| `nimbit-gateway-credential.json` | Die zwischengespeicherten Datenzugangsdaten des Gateways für die Plattform-Ausgänge. | Mit dem nächsten Token werden neue angefordert. |
| `nimbit-mqtt-credential.json` | Die Tenant-Zugangsdaten, zwischengespeichert von einer Box, die als Servicekonto läuft. | Neue werden angefordert. |

Eine Box, die sich als Gateway anmeldet, hält kein Passwort. Ihre Anmelde-Tokens gelten 5 Minuten und ihre Ingest-Tokens höchstens 10 Minuten. Das einzige Geheimnis neben dem Schlüssel sind die zwischengespeicherten Datenzugangsdaten.

## Arbeit {#work}

| Datei | Enthält | Bei Verlust |
| --- | --- | --- |
| `proposals.yaml` | Thing-Typen und Things mit ihrem Status. | Die Erkennung schlägt wieder alles vor. |
| `edits.yaml` | Umbenennungen, Zusammenführungen, Einheiten und Skalierungen, die Sie in der Web-Oberfläche gemacht haben. | Die Erkennung schlägt wieder die generierten Namen vor. |
| `mapping.json` | Welche Quelladresse welches Thing und welchen Messwert speist. | Das nächste Anwenden schreibt sie neu. |
| `tsflux-stream/<output>/`, `spool/<output>/` | Werte, die die Plattform noch nicht akzeptiert hat. | Diese Werte gehen verloren. |
| `config.ui.toml` | Schlüssel, die der Einrichtungsbildschirm geschrieben hat. | Der Agent ist nicht verbunden, bis Sie sie wieder setzen. |

## Was zu sichern ist {#what-to-back-up}

Sichern Sie das ganze Verzeichnis, während der Agent gestoppt ist, oder mindestens `gateway_key.pem`, `gateway.json`, `tenant.json`, `proposals.yaml`, `edits.yaml`, `mapping.json` und Ihre `periscope.toml`. Die Kopie enthält den privaten Schlüssel der Box: Bewahren Sie sie auf wie ein Passwort.

Die Warteschlangen müssen Sie nicht sichern. Eine wiederhergestellte Kopie darf nur auf einer Box laufen. Zwei Boxen mit demselben Schlüssel und derselben MQTT-Client-ID trennen sich gegenseitig.

Um eine Box zu ersetzen, statt sie wiederherzustellen, siehe [Eine Box ersetzen](./replace-a-box.mdx).
