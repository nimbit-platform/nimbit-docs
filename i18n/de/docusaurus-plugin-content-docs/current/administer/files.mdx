Halten Sie Dokumente und Bilder an einem Ort, zeigen Sie sie dann auf Dashboards, in Berichten und bei Things, oder teilen Sie eine Datei über einen zeitlich begrenzten Link.

## Bevor Sie beginnen {#before-you-start}

- Sie müssen Dateien erstellen, aktualisieren oder löschen dürfen. **Administrator**, **Manager** und **Modellierer** dürfen das. **Viewer** sieht Dateien nur dort, wo ein Dashboard, ein Bericht oder ein Thing sie zeigt.

## Hochladen und ordnen {#upload-and-organize}

1. Öffnen Sie **Arbeitsbereich › Dateien**. Wechseln Sie zwischen **Listenansicht** und **Rasteransicht** und finden Sie mit **Dateien durchsuchen** eine Datei nach ihrem Namen.
2. Wählen Sie **Hochladen** oder ziehen Sie Dateien in den Explorer. Der Dialog zeigt die **Maximale Dateigröße**.
3. Um einen Ordner anzulegen, wählen Sie **Neuer Ordner**. In einem Ordner wählen Sie **Neuer Unterordner**.
4. Um zu verschieben oder zu kopieren, wählen Sie bei einer Datei oder einem Ordner **Ausschneiden** oder **Kopieren**, öffnen Sie den Zielordner und wählen Sie **In Ordner einfügen**. **Umbenennen** funktioniert genauso.

Die Ordner **Things** und **Thing Typen** enthalten je einen Ordner pro Thing oder Thing-Typ. Sie können sie hier nicht anlegen, umbenennen, verschieben oder löschen; legen Sie Dateien hinein. Der Ordner `_internal_` enthält Dateien, die andere Seiten der App verwenden.

## Eine Datei taggen {#tag-a-file}

Wählen Sie bei einer Datei **Tag** und fügen Sie Tags hinzu. Tags helfen Ihnen, Dateien zu finden und zu filtern.

## Einen Link teilen {#share-a-link}

1. Wählen Sie bei einer Datei **Link teilen**.
2. Wählen Sie unter **Läuft ab in**, wie viele Stunden oder Tage der Link gültig ist.
3. Wählen Sie **Link generieren** und dann **Link kopieren**.

Jeder mit dem Link kann die Datei öffnen, bis er abläuft.

## Ask Nimble eine Datei zitieren lassen {#let-ask-nimble-cite-a-file}

Öffnen Sie die Details der Datei und setzen Sie **Suchindex** auf **Antworten dürfen diese Datei zitieren** oder **Wird beim Beantworten von Fragen nicht verwendet**. Dateien im eigenen Ordner eines Datensatzes sind standardmäßig aktiviert. Ohne Berechtigung, Dateien zu ändern, ist die Einstellung schreibgeschützt.

## Dateien löschen {#delete-files}

1. Wählen Sie bei einer Datei oder einem Ordner **Löschen** und bestätigen Sie. Das Löschen lässt sich nicht rückgängig machen.
2. Zeigt das Dateilisten-Widget eines Dashboards den Ordner, listet **Ordner wird von Widgets verwendet** zuerst die Dashboards auf. Nach dem Löschen zeigen diese Widgets weniger Dateien oder keine.
3. Das Löschen aus `_internal_` fragt ein zweites Mal (**Trotzdem löschen**), weil andere Seiten dadurch kaputtgehen können.

## Prüfen, ob es funktioniert hat {#check-that-it-worked}

Die Datei erscheint im Ordner mit ihrer **Größe**, ihrem **Typ**, **Geändert** und **Tags**. Ein geteilter Link öffnet die Datei in einem privaten Browserfenster.

## Wenn es nicht funktioniert {#if-it-doesnt-work}

- **Sie können in Things oder Thing Typen keinen Ordner anlegen**: Diese Ordner gehören zu ihrem Thing. Öffnen Sie den Ordner des Things und legen Sie den Ordner dort an.
- **Der Upload wird abgelehnt**: Die Datei überschreitet die **Maximale Dateigröße**, die der Upload-Dialog zeigt.
- **Ein Dashboard zeigt keine Dateien**: Sein Dateilisten-Widget verweist auf einen Ordner, den Sie geändert oder gelöscht haben.
- **Eine Vorschau fehlt**: **Vorschau** gibt es nicht für jeden Dateityp. Verwenden Sie **Herunterladen**.
