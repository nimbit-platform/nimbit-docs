Die Tabs unter **Administration › Mandanteneinstellungen**, die für alle im Tenant gelten. Nur die Rolle **Administrator** kann sie öffnen (sie braucht die Berechtigung, den Tenant zu aktualisieren).

Änderungen auf **Allgemein**, **Funktionen**, **Theme** und **Email** werden gemeinsam mit **Speichern** gespeichert. Ein Badge zeigt **Ungespeicherte Änderungen**. **Zurücksetzen** setzt Themefarben, Branding-Bilder und E-Mail-Einstellungen nach einer Bestätigung zurück und lässt sich nicht rückgängig machen.

## Allgemein {#general}

| Einstellung | Bedeutung |
| --- | --- |
| **Name**, **Tenant Id** | Schreibgeschützt. |
| **Anzeigename** | Der Name, den Personen in der App sehen. |
| **Zeitzone**, **Sprache** | Standardwerte für den Tenant. |
| **Erlaubte Hosts** | Seiten, die eingebettet werden dürfen, zum Beispiel auf Canvases. Ein Host pro Zeile, etwa `grafana.example.com`, oder `*.example.com` für alle Subdomains. Leer erlaubt keine. |
| **Branding-Bilder** | **Favicon** (`.ico`, 48 × 48), **Standardlogo**, **Logo für den hellen Modus**, **Logo für den dunklen Modus** (PNG oder SVG, bis 5 MB) und **Titelbild** (PNG, SVG, JPEG oder WebP, bis 5 MB). Siehe [Ihren Tenant mit Ihrer Marke gestalten](./branding.mdx). |

## Funktionen {#features}

| Funktion | Wirkung |
| --- | --- |
| **Dashboard-Hierarchie** | Gruppiert Dashboards in einem Baum aus Standorten, Gebäuden oder Bereichen, mit einem Schalter **Tabelle** / **Hierarchie** bei den Dashboards. Schalten Sie sie aus, ist der Baum verborgen. Knoten und einsortierte Dashboards kehren zurück, wenn Sie sie wieder einschalten. |
| **Dashboards öffnen in** | **Tabelle** oder **Hierarchie**. Gilt für Personen, die Dashboards noch nicht benutzt haben. Danach öffnen sie dort, wo jede Person zuletzt war. |
| **Nimble fragen und Knowledge** | Der KI-Assistent und der Bereich Knowledge. Auf Ihrer Installation möglicherweise nicht verfügbar. Eine Funktion kann **On until** mit einem Datum zeigen. |
| **Verwaltungsschale** | Stellt die Things, die Sie freigeben, über die schreibgeschützte AAS-API bereit. Ist sie an, legt **Vorgaben für veröffentlichte Verwaltungsschalen** Herstellername, Kontakt-E-Mail und Kontakt-URL für Things fest, die keine eigenen setzen, und zeigt schreibgeschützt **Kennungen der Verwaltungsschalen**. Siehe [Things als Verwaltungsschalen veröffentlichen](../share/asset-administration-shell.mdx). |
| **Produktlinks** | Ein öffentlicher Link und QR-Code je Thing und Thing-Typ. Setzt **Verwaltungsschale** voraus. Siehe [Produktlinks und QR-Codes erstellen](../share/product-links.mdx). |
| **Dataspace-Angebote** | Veröffentlicht ausgewählte Verwaltungsschalen als Angebote im eigenen Dataspace-Connector, eingerichtet auf der Karte **Dataspace-Connector** unter den Funktionen. Setzt **Verwaltungsschale** voraus. Siehe [Things im eigenen Dataspace-Connector anbieten](../share/dataspace-offers.mdx). |

## Theme {#theme}

| Einstellung | Bedeutung |
| --- | --- |
| **Standarddarstellung des Tenants** | **Hell** oder **Dunkel**, für Personen ohne eigene Vorgabe. Sie können sie mit dem Theme-Schalter im Kopfbereich überschreiben. |
| Theme-Editor | Farben, Layout und Schatten je Farbmodus. Wählen Sie eine Vorschau, um diesen Modus zu bearbeiten. |

## Email {#email}

| Anbieter | Bedeutung |
| --- | --- |
| **Systemstandard** | E-Mails gehen vom Mailserver der Plattform aus. Keine Einrichtung. |
| **Microsoft 365** | Mit Microsoft anmelden (OAuth2). Wählen Sie zuerst **Speichern**, dann **Mit Microsoft anmelden**. Optional **Geteilte Postfachadresse**, um von dort zu senden. Wählen Sie **Abmelden**, bevor Sie den Anbieter wechseln. |
| **Eigener SMTP-Server** | Ihr eigener Mailserver. Schalten Sie **Benutzerdefiniertes SMTP aktivieren** ein. |

Felder für eigenes SMTP: **Host**, **Port** (standardmäßig 587), **Benutzername**, **Passwort**, **Absender** und die Verschlüsselung **STARTTLS** oder **SSL/TLS**. **Test email senden** sendet eine E-Mail mit der aktuellen Konfiguration und braucht einen aktivierten Anbieter.

## Statistiken {#statistics}

Schreibgeschützt.

| Eintrag | Zeigt |
| --- | --- |
| **Zeilenanzahl**, **Speicher** | Messungen und der Platz, den sie belegen, jeweils mit dem Wert für **Gestern**. |
| **Gesamter Speicherverbrauch für Dateien** | Größe aller Dateien im Tenant. |
| Flächendiagramme, Tabelle **Letzte 30 Tage** | Zeilenanzahl und Speicher pro Tag. **Keine Daten verfügbar**, bevor die erste Messung eintrifft. |

## Zeitpläne {#schedules}

Schreibgeschützte Liste der Aufgabenzeitpläne des Tenants.

| Spalte | Bedeutung |
| --- | --- |
| **URI**, **Eigentümer** | Was läuft und wem es gehört. |
| **Zeitsteuerung** | Zum Beispiel `every 15m`, `cron: 0 6 * * *` oder `once @ date`. |
| **Aufruf**, **Status**, **Aktiviert** | Wie es läuft, in welchem Zustand und ob es an ist. |
| **Letzter Lauf**, **Nächster Lauf** | Laufzeiten. |

Datenlöschungen erscheinen hier, solange sie geplant sind oder laufen. Siehe [Daten löschen](./delete-data.mdx).

## Daten {#data}

Zeigt die Datenspeicher allen, die sie lesen dürfen. **Aufgezeichnete Daten löschen** braucht die Berechtigung „Datenlöschung“. Siehe [Daten löschen](./delete-data.mdx).

## Pakete {#packs}

Pakete sind Startinhalte von Nimbit: E-Mail-Vorlagen und -Bausteine, Interfaces, Dashboards und Canvases. Installierte Elemente gehören Ihrem Tenant, und Sie können sie bearbeiten.

| Zustand | Bedeutung |
| --- | --- |
| **Nicht installiert** | Nicht in Ihrem Tenant. |
| **Aktuell** | Installiert und gleich der ausgelieferten Version. |
| **Update verfügbar** | Nimbit liefert eine neuere Version aus. |
| **Bearbeitet** | Sie haben es geändert. |
| **Gelöscht** | Sie haben es gelöscht. |

| Schaltfläche | Wirkung |
| --- | --- |
| **Installieren**, **Fehlende Elemente installieren** | Fügt den Inhalt des Pakets hinzu. |
| **Zurücksetzen** | Ersetzt ein Element durch die ausgelieferte Version oder legt es neu an, wenn es gelöscht wurde. Ihre Änderungen gehen verloren. |
| **Deinstallieren** | Der Inhalt bleibt als Ihr eigener, erhält aber keine Updates. Eine erneute Installation legt neue Kopien an. Ein Paket, das andere voraussetzen oder dessen Inhalt in Gebrauch ist, lässt sich nicht deinstallieren. |

Filtern Sie oben nach **Inhaltstyp**.

## Verbindungen {#connections}

Provisionierungs- und Messaging-Anbieter des Tenants.

| Eintrag | Bedeutung |
| --- | --- |
| **Von Nimbit verwaltet** | Interne Anbieter. Sie können sie ein- oder ausschalten, aber nicht löschen. Beim Ausschalten fragt **Deaktivieren**: Things, die ihn verwenden, verlieren ihre Verbindungen und können keine Nachrichten senden. |
| **Tenant-Verbindung** | Die Adresse, mit der sich ein Thing verbindet. Ersetzen Sie `<deviceId>` durch die ID des Things. |
| Zugangsdaten | Werden nicht gespeichert. Erzeugte Tokens sind nur in der aktuellen Browsersitzung verfügbar. |
