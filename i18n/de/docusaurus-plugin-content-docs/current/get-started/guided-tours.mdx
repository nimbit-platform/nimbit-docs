IoT Breeze hat geführte Touren: kurze Rundgänge, die auf jeden Teil eines Bildschirms zeigen und warten, während Sie es ausprobieren. Ein Guide ist eine Reihe von Touren, die aufeinander aufbauen. Wählen Sie unten eine Tour, um sie in Ihrem IoT Breeze zu öffnen; sie startet, sobald der Bildschirm geladen ist.

Die Links öffnen die Adresse, die neben **IoT Breeze öffnen** oben auf dieser Seite eingestellt ist. Läuft Ihr IoT Breeze auf einer eigenen Domain, stellen Sie sie zuerst dort ein.

Sie können Touren auch in IoT Breeze über das Hilfemenü starten. Dort zeigt jede Tour, ob Sie sie abgeschlossen haben.
