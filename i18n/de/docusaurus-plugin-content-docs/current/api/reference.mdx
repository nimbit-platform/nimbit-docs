Jede API stellt ihre eigene Referenz auf dem Host bereit, auf dem Sie IoT Breeze öffnen. Die Referenzen werden aus der Version erzeugt, die Ihre Installation ausführt. Sie passen also immer dazu, und **Test Request** sendet den Aufruf an Ihre eigene API.

<ApiReferenceLinks />

Die Links verwenden Ihre IoT-Breeze-Adresse. Zeigen sie auf den falschen Host, stellen Sie Ihre Adresse über den Pfeil neben **IoT Breeze öffnen** oben auf der Seite ein.

Um einen Endpunkt aus der Referenz aufzurufen, authentifizieren Sie sich zuerst: mit einem API-Schlüssel oder einem Benutzer-Token für die Query- und Plattform-API, mit Geräte- oder Tenant-Zugangsdaten für die Ingest-API. Welche Header dafür nötig sind, steht unter [Authentifizierung](./authentication.mdx).
