IoT Breeze liefert ein Interface mit. Es erscheint unter **Geräte › Interfaces** auf dem Tab **Vorinstalliert** und ist schreibgeschützt: Sie können es anhängen, seine Versionen vergleichen und auf eine neuere aktualisieren, aber nicht bearbeiten.

## Temperature Sensing {#temperature-sensing}

Umgebungstemperatur und Luftfeuchtigkeit. Sein Reifegrad ist **Stabil**.

| Eigenschaft | Wert |
| --- | --- |
| Anzeigename | **Temperature Sensing** |
| Name | `temperature-sensing` |
| Aktuelle Version | v1 |
| Reifegrad | **Stabil** |

| Feld | Art | Typ | Einheit | Anzeigename | Aliase |
| --- | --- | --- | --- | --- | --- |
| `temperature` | Messwert | `numeric` | `°C` | Temperature | `temp` |
| `humidity` | Messwert | `numeric` | `%` | Humidity | `rh`, `relativeHumidity` |

Beide Felder sind als **Zeitreihenrelevant** markiert.

### Startinhalte {#starter-content}

Das Paket **Temperature sensing** ergänzt Inhalte, die auf diesem Interface aufbauen. Ein Tenant-Admin installiert es unter **Geräte › Pakete**; siehe [Tenant-Einstellungen](../administer/tenant-settings.mdx).

| Element | Was es ist |
| --- | --- |
| Dashboard **Temperature Sensing** | Ein Smart-Dashboard mit zwei Gauges: Temperatur von -20 bis 60, Luftfeuchtigkeit von 0 bis 100. |
| Canvas **Room overview** | Kacheln mit Komfortbereichen, Gauges und einem 24-Stunden-Diagramm für einen Raum. Funktioniert für jedes Thing, dessen Typ das Interface implementiert. |
