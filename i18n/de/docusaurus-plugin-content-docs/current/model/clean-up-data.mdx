Schicken Sie jede eingehende Nachricht eines Thing-Typs vor dem Speichern durch einen kleinen Graphen aus Schritten, die **Transformations-Pipeline**. Das Beispiel rechnet eine Temperatur von Fahrenheit in Celsius um.

## Voraussetzungen {#before-you-start}

- Ein [Thing-Typ](./create-thing-type.mdx) mit einem veröffentlichten Messwert `temperature`.
- Ein Desktop-Browser. Der Pipeline-Editor ist auf dem Smartphone nicht verfügbar.
- Ihre Rolle darf Thing-Typen bearbeiten.

## Schritte {#steps}

1. Öffnen Sie **Einstellungen › Onboarding › Thing Typen** und wählen Sie den Thing-Typ. Auf der **Übersicht** zeigt die Karte **Pipeline** die **Transformation** als **Aktiv** oder **Inaktiv**. Wählen Sie **Editor öffnen** oder nutzen Sie **Weitere Aktionen › Pipeline-Editor öffnen**. Der Editor öffnet sich als **Transformationsregel (Version 1)** mit einem Knoten **Request**, der mit einem Knoten **Response** verbunden ist.
2. Ziehen Sie einen Knoten **Expression** aus dem Bereich **Components** auf die Fläche. Verbinden Sie **Request** mit ihm und ihn mit **Response**: Ziehen Sie vom Anschluss rechts an einem Knoten zum Anschluss links am nächsten.
3. Wählen Sie am Knoten **Edit Expression** und fügen Sie eine Zeile hinzu. Setzen Sie **Key** auf `data.temperature` und **Expression** auf `(data.temperature - 32) * 5 / 9`.
4. Öffnen Sie den **Simulator** in der linken Seitenleiste. Er füllt eine Testnachricht mit Zufallswerten für Ihre Messwerte. Setzen Sie `data.temperature` auf `212` und wählen Sie **Run**. Das Ergebnis zeigt `data.temperature` als `100`, der Rest der Nachricht bleibt unverändert.
5. Wählen Sie **Speichern**. Es ist deaktiviert, solange der Graph ungültig oder unverändert ist. Fahren Sie mit der Maus über das Statussymbol im Kopfbereich, um den Grund zu sehen.
6. Wählen Sie **Aktivieren**.

## Wählen, was jeder Schritt tut {#choose-what-each-step-does}

Was bei **Response** ankommt, wird gespeichert, behalten Sie also die Form der Nachricht: `data` enthält die Messwerte, `geo` den Standort, `tags` die Eigenschaften, die als **Zeitreihenrelevant** markiert sind. Ein Feld, das das Schema des Thing-Typs nicht kennt, wird verworfen, ein neuer berechneter Wert braucht also einen eigenen Messwert.

| Um … | Fügen Sie hinzu |
| --- | --- |
| Nachrichten gegen ein JSON-Schema zu prüfen | Einen Knoten **Request**: Wählen Sie **Configure** und dann **Import** mit einer Beispiel-Payload, um zu beginnen. |
| Werte zu berechnen oder zu überschreiben | Einen Knoten **Expression**: je ein **Key** und eine **Expression** pro Ausgabefeld. |
| Werte in Bezeichnungen zu verwandeln, zum Beispiel einen Statuscode | Einen Knoten **Decision Table**: **Edit Table**. Zeilen werden von oben nach unten geprüft. |
| Nachrichten auf verschiedene Zweige zu schicken | Einen Knoten **Switch**: eine Bedingung pro Ausgangsanschluss. |
| Zu tun, was die anderen nicht können | Einen Knoten **Function**: **Edit Function**, in JavaScript. |

Ausdrücke verwenden die ZEN-Sprache des Open-Source-Editors [GoRules](https://docs.gorules.io/), der auch Entscheidungstabellen und Funktionen dokumentiert.

## Eine laufende Pipeline ändern {#change-a-pipeline-that-is-live}

Eine Pipeline hat Versionen, und nur eine ist **Aktiv**. **Versionen** öffnet die Liste, in der Sie aus dem aktuellen Graphen eine **Neue Version** erstellen oder die **Version wechseln** können. **Deaktivieren** stoppt die Pipeline, und Daten werden so gespeichert, wie das Gerät sie gesendet hat.

Bearbeiten Sie die aktive Version, bleiben Ihre Änderungen ein Entwurf, bis Sie sie anwenden. Eine schwebende Werkzeugleiste bietet **Entwurf anwenden**, **Entwurf zurücksetzen** (bestätigen Sie **Verwerfen**) und einen Schalter zwischen **Entwurf** und **Unterschied zwischen Entwurfsdiagramm und aktivem Diagramm anzeigen**. **Entwurf anwenden** ist aus, solange der Graph ungültig ist.

## Prüfen, ob es geklappt hat {#check-that-it-worked}

Auf der **Übersicht** des Thing-Typs zeigt die Karte **Pipeline** die **Transformation** als **Aktiv**. Senden Sie eine Nachricht oder wählen Sie auf der Seite eines Things **Daten senden** und sehen Sie sich den gespeicherten Wert in der **Übersicht** des Things oder in [Telemetrie über die Zeit untersuchen](../watch/explore-telemetry.mdx) an: `100`, nicht `212`.

## Wenn es nicht funktioniert {#if-it-doesnt-work}

- **Eine Nachricht taucht nie auf**: Eine Nachricht, die in der Pipeline scheitert, durch eine Schemaprüfung, einen Ausdrucks- oder Funktionsfehler oder ein Timeout, wird nicht gespeichert. Der Absender einer HTTP-Nachricht erhält einen Fehler. Lassen Sie dieselbe Nachricht im **Simulator** laufen, um den Knoten zu sehen, der gescheitert ist.
- **Ein berechneter Wert fehlt**: Das Schema hat keinen Messwert mit diesem Namen. Fügen Sie den Messwert hinzu und veröffentlichen Sie.
- **Aktivieren ist deaktiviert**: Sie haben ungespeicherte Änderungen, wählen Sie also zuerst **Speichern**, oder der Graph ist ungültig. Ein gültiger Graph hat einen Knoten **Request**, einen Knoten **Response** und einen Pfad dazwischen.
- **Eine Nachricht wird nach einem langsamen Schritt abgelehnt**: Eine Transformation hat ein Zeitlimit, und eine Nachricht, die es überschreitet, wird abgelehnt.
