Jede Datei verweist auf die Seite, die ihre Verwendung erklärt. Dateien sind versioniert; nehmen Sie die neueste Version, sofern eine Seite nichts anderes sagt. Prüfen Sie einen Download anhand seiner SHA-256-Prüfsumme, bevor Sie ihn auf einem Gateway installieren.

## Periscope {#periscope}

Periscope, der NimBit-Edge-Agent, ist lizenzierte Software und kein öffentlicher Download. Das Paket und eine Lizenz erhalten Sie bei [info@nimbit.de](mailto:info@nimbit.de). Folgen Sie dann [Periscope installieren und die erste Quelle streamen](./gateways/periscope/install.mdx).

## Pakete {#packs}

Pakete bündeln Thing-Typen, Interfaces und Dashboards für eine Art von Ausrüstung. Pakete, die mit IoT Breeze ausgeliefert werden, installieren Sie unter **Geräte › Pakete**. Pakete zum Download werden hier aufgeführt.
