Füllen Sie Diagramme und testen Sie Dashboards oder Regeln, bevor das echte Gerät online ist. IoT Breeze sendet die Daten für das Thing, wie es ein Gerät tun würde. Um echte Hardware zu verbinden, verwenden Sie [Daten über MQTT senden](./mqtt.mdx) oder [Daten über HTTP senden](./http.mdx).

## Bevor Sie beginnen {#before-you-start}

- Ein Thing mit einem veröffentlichten Thing-Typ. Siehe [Ein Thing registrieren](../model/register-thing.mdx).
- Die Berechtigung, Daten an Geräte zu senden. Ohne sie werden die Schaltflächen nicht angezeigt.

## Schritte {#steps}

### Eine Nachricht senden {#send-one-message}

1. Öffnen Sie das Thing (**Geräte › Things**).
2. Wählen Sie **Weitere Aktionen**, dann **Daten senden**. Der Tab **Einmal senden** öffnet sich. Bei einem Thing, das noch nie Daten gemeldet hat, bietet auch die **Übersicht** die Option **Testnachricht senden**.
3. Jeder Messwert des Thing-Typs ist eine Zeile mit **Telemetrie** und **Wert**. Entfernen Sie den Haken bei Messwerten, die Sie nicht senden möchten, oder wählen Sie **Alle Messwerte einschließen**.
4. Wählen Sie unter **Zeitstempel** **Jetzt** oder **Zeit wählen…**.
5. Wählen Sie **Nachricht senden**.

Um Standort oder Tags hinzuzufügen, bearbeiten Sie die Nachricht als JSON. Löschen Sie einen Messwert, um ihn wegzulassen.

### Eine Simulation starten {#run-a-simulation}

1. Wählen Sie **Weitere Aktionen**, dann **Gerät simulieren…**. Der Tab **Simulieren** öffnet sich.
2. Wählen Sie **Laufzeit**: 15 Minuten, 30 Minuten, 1 Stunde oder 4 Stunden.
3. Wählen Sie **Alle**: wie oft eine Nachricht gesendet wird, von 1 Sekunde bis 5 Minuten. Standard sind 10 Sekunden.
4. Wählen Sie für jeden Messwert einen **Verlauf** sowie **Min** und **Max**. Die **Vorschau** zeichnet das Ergebnis. Wählen Sie mindestens einen Messwert.
5. Wählen Sie **Simulation starten**.

| Messwerttyp | Verläufe |
| --- | --- |
| Numerisch | **Zufällig**, **Gleichmäßig**, **Welle**, **Rampe**, **Stufen**, **Ausreißer**, **Konstant**, **Aus** |
| Boolean | **Meist true (95 %)**, **Alle 5 min wechseln**, **Zufällig**, **Immer true**, **Immer false**, **Aus** |
| Text | **Konstant**, **Aus** |

**Aus** lässt den Messwert weg.

### Eine laufende Simulation steuern {#control-a-running-simulation}

Die Simulation läuft in IoT Breeze und läuft weiter, wenn Sie die Seite verlassen. Ein Banner auf der Seite des Things zeigt **Simulation läuft**, das Intervall, die verbleibende Zeit und die gesendeten Nachrichten.

| Schaltfläche | Wirkung |
| --- | --- |
| **+15 min** | Verlängert um 15 Minuten. |
| **Bearbeiten…** | Öffnet das Formular. **Simulation neu starten** übernimmt Änderungen. |
| **Stopp** | Beendet die Simulation. |

## Prüfen, ob es geklappt hat {#check-that-it-worked}

Die Werte erscheinen innerhalb einer Sekunde unter **Live-Werte** auf der **Übersicht** des Things. **Letztes Signal** zeigt die aktuelle Uhrzeit.

## Wenn es nicht funktioniert {#if-it-doesnt-work}

- **Die Schaltflächen fehlen**: Ihnen fehlt die Berechtigung, Daten an Geräte zu senden.
- **Das Banner meldet „Simulation beendet: Die Daten konnten nicht gesendet werden“**: Wählen Sie **Ausblenden**, prüfen Sie, ob der Thing-Typ veröffentlicht ist, und starten Sie erneut.
- **Simulierte Werte stehen im Verlauf eines echten Geräts**: Diagramme unterscheiden sie nicht. Entfernen Sie sie unter **Arbeitsbereich › Arbeitsbereich-Einstellungen › Daten** mit **Simulierte Daten**, nachdem Sie laufende Simulationen gestoppt haben. Messwerte, die Ihre Geräte gesendet haben, bleiben unberührt.
