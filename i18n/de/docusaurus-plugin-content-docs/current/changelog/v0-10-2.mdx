Released 26 March 2026. This release fixes forms and the rule designer, and gives the group page a new design.

## Improved

**Groups**
- The group page has a new design.

**Automation**
- In the rule designer, you can no longer select the active version while a draft is available.

## Fixed

- Forms: closing a form no longer shows the unsaved changes dialog when nothing changed.
- Rule designer: **Apply draft** now works, and rule validation reports errors correctly.
- Groups: the default translation in the group form is no longer missing in either language.
- Values: pressing Enter in the update value form now works.
- Dashboards: the dashboard title is displayed correctly.
- Reports: reports now switch language on the standalone report page.
