Released 5 March 2026. This release adds new email sign-in methods. It also fixes forms in several areas. It includes the changes of 0.9.1.

## New

**Sign-in**
- New email authentication methods.

**Filters and rules**
- A case-insensitive "not contains" operator is now available in filters and rules.

## Improved

**Navigation**
- The left sidebar closes when you open a create form.

**Mail templates**
- Mail templates are highlighted, and navigation in the mail template form is updated.

## Fixed

- Widgets: the measures table in widget forms, for example the combination chart, now works.
- Thing types: **Created by** is no longer shown as undefined on the thing type page.
- Mail templates: the **Save** button in the mail template form works again.
- Event types: fixed the sidebar on the event type page.
- Forms: fixed spacing in the action form and the invite user form.
