Released 2 April 2026. This release fixes problems in reports, canvas, email settings and the heatmap widget.

## Improved

**Canvas**
- Saving a canvas now gives clearer feedback.

**Things**
- The thing page now shows documents.

## Fixed

- Reports: updating a widget on the report page now works.
- Heatmap widget: the time range is now applied correctly.
- Canvas and values: the **Save** button in the update value dialog is now disabled when there is nothing valid to save.
- Email: the SMTP password field is no longer required.
