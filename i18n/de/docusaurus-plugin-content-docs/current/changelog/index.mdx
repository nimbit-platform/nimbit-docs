Dieser Bereich listet auf, was sich in jedem Release von IoT Breeze geändert hat, das neueste zuerst. Versionen sind als `0.minor.patch` nummeriert: Eine neue Minor-Nummer bringt neue Funktionen, eine neue Patch-Nummer bringt Fehlerbehebungen.
