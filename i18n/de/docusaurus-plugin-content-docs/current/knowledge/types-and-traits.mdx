The building blocks of the knowledge graph's data model, under **Settings › Knowledge setup › Data model** (tabs **Types**, **Traits**, **Library**).

## Types

| Property | Rule |
| --- | --- |
| Name | PascalCase, unique in the tenant, cannot be renamed. |
| Owner **System** | Ships with the platform. Read-only, but you can extend it with **Extend this type**. **Remove extension** takes your additions off. |
| Owner **Tenant** | Yours. Composed from traits plus your own properties and relations. |
| Pack badge | The type came from a Library pack and is locked to it. |
| Versions | A new type saves as v1. Each later save is a new version. **Versions** shows a diff of added, retyped and no-longer-declared fields. |
| Delete | Refused while the type has records, another type links to it, or a mapping uses it. |

| Field option | Effect |
| --- | --- |
| **Required** | Records must carry the field. |
| **Indexed** | Fast filtering. |
| **Full-text** | Searchable by its words. |
| **Synonyms** | Comma-separated alternative words, per language, used for search and by Ask Nimble. Available on types and relations. |

A relation has a free-form name such as `feedsInto`, a target type, a description and synonyms. Each field shows its origin: a trait, the system type, a pack, or **Added by this tenant**.

Narrowing a type does not remove values from existing records. The field is only dropped from the type.

## System types

| Type | Is |
| --- | --- |
| `Thing` | A device, replicated from the platform. |
| `ThingType` | A thing type. |
| `Asset` | A location or organizational node in your asset hierarchy (site, hall, line) that equipment is placed under. |
| `MaintenanceOrder` | A maintenance order. |
| `MaintenanceRule` | A maintenance rule extracted from a manual. Created through extraction and review. |
| `Incident` | An incident, replicated from the platform. |
| `Document`, `DocumentChunk` | A file and its indexed passages. |
| `DocumentAnnotation` | A region of a drawing linked to the thing it depicts. |
| `Object3D` | A part of a 3D model linked to the thing it represents. |
| `Dashboard`, `Canvas` | Visualizations. |
| `AclGroup`, `UserAcl` | Groups and the groups each user belongs to, used for access. |
| `MeasureSpecProposal` | A measure specification (unit, scaling, bounds) proposed from a manual. |

## Traits

| Trait | Gives a record | Notes |
| --- | --- | --- |
| **Hierarchical** | `parent`, `root`, `path`: a place in the containment tree. | Needed for sites and levels. |
| **Describable** | Name, description, translations, tags, alternative names. | Name is searchable. |
| **Aliased** | Identifiers it has in other systems (system, type, value). | Mappings match incoming rows by alias. |
| **Governed** | Whether access control applies, plus the groups and users that may read it. | A governed record with no grant can be hidden. |
| **Measured** | The measurements it exposes, with units and ranges. | Reserved to system types. |
| **Connectivity** | Connection state, last connected, last disconnected. | |
| **Lifecycle** | Current status and status history. | Status stores your own label. |
| **Spatial** | Geographic coordinates, a free-text location. | |
| **Scheduled** | Planned and actual start and end. | |
| **Sourced** | Source system, source ID, last updated in source. | |
| **Versioned** | Valid from, valid to, and the record it supersedes. | |
| **Attributed** | Custom typed key-value attributes. | |
| **Extensible** | Tenant-defined custom fields. | Flat values only. |
| **Embedded** | A vector, so the record is found by meaning. | Off by default. |
| **Searchable** | Harvested tags and identifiers for keyword search. | Filled by the platform, not by hand. |
| **Imaged** | Pictures, internal or external. | |
| **Pending** | Links to records that did not exist yet when the data arrived. | Resolved by reconciliation. |

## Library packs

| Item | Meaning |
| --- | --- |
| **Data models** | Packs that install types. Installing a type also installs the pack types it links to. Installed types are yours but locked to the pack. |
| **Integrations** | Mapping templates and connector presets. Copying a template under a source name gives you a mapping you can change. Creating it installs only the types you lack. |
| **Upgrade to version** | Shown when a pack has a new version. **Review upgrade** checks it against your types first. If it does not fit, nothing changes. |
| **Uninstall** | Removes the pack's types. Refused while a type has records, another type links to one, or a mapping uses one. Mappings made from templates stay. |

If the Library is empty, no packs ship with the installation. Platform admins add them.
