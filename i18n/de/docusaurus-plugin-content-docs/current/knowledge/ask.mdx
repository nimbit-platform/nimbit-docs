Ask in plain words, read the answer, and check the sources under it. To understand what Nimble reads and how it checks an answer, see [How Ask Nimble answers](./ask-nimble-answers.mdx).

<TourLink id="explore-find-your-way" />

## Before you start

- **Ask Nimble and Knowledge** must be on for your tenant, and your role needs permission to read and run Knowledge. See [Knowledge and AI](./index.mdx).
- Nimble can only find what the graph holds. For places, see [Map your sites and buildings](./map-sites.mdx).

## Ask

1. Open Ask Nimble. Press Ctrl+I (⌘+I on a Mac) on any page to open it beside the page, or open **Knowledge › Ask Nimble** for the full page. The shortcut does not work while you type in a text field.
2. Type a question in **Ask about your graph…**, or pick one of the **Suggested questions**.
3. Watch the steps line, for example **Reading the hierarchy**. Open it for detail.
4. To focus on one record or place, select **Add context** and pick it. Nimble shows **Asking about** that record. On a record elsewhere in the app, **Ask about this** does the same.

Examples:

| About | Ask |
| --- | --- |
| Places | "What is in Hall 2?" "Where is Pump 7 located?" |
| Counts and status | "How many things are there by status?" "Which things are offline?" |
| Readings | "What are the latest values of Pump 7?" "How did Pump 7 run over the last 7 days?" |
| Causes | "Why is Pump 7 offline?" |
| Connections | "What is Pump 7 linked to?" |
| Documents | "Which documents cover Pump 7?" "What does the manual say about the seal interval?" |
| Maintenance | "Which maintenance orders are open in Hall 2?" |

If a question is too wide or fails, name a place or a type: "Which `Pump` things in Hall 2 are offline?"

## Read the answer and its sources

1. Read the text. Record names are links you can open.
2. Look below the text. Lists appear as **Rows**, with sort and paging. **View all in Explore** opens the full list and **Export CSV** saves it. Readings appear as charts with a time range you can change. **What moved** shows signals that changed in a window.
3. Match each `[n]` to a source under the answer: **Graph** (a record), **Live value** (a reading and its time) or **Document** (a passage; open it and select **Open at page**).
4. Open **How Nimble answered** for the steps, and **Details** for the model, the number of model calls and the run ID.

Each record also offers **Open record**, **Open in graph**, **Ask about this** and **Use as context**.

## Narrow what Nimble reads

Above the question field, the **Reads** strip has **Records**, **Readings** and **Docs**. Switch one off to exclude that source from the next question. Once you add context, a scope picker beside **Docs** (**Self**, **Inherited**, **Subtree**) sets which documents around that record are read.

To pick a model for the chat, use the model menu in the field's footer. The default is **Auto**. See [Choose the AI model](./ai-model.mdx).

## Rate it and follow up

- Choose **Helpful** or **Not helpful** (or **Right** or **Wrong**). For a wrong answer pick **Wrong data**, **Wrong approach**, **Incomplete** or **Unclear**, and add a note.
- Pick a suggestion under **Ask next**, or type a follow-up. "And last week?" keeps the context.
- **Conversations** lists earlier chats under **Today**, **Yesterday** and **Last 7 days**. Search or delete one. **New chat** starts clean.

## Check that it worked

The answer cites sources, the **Details** line names the model (or zero model calls for a count), and the footer reads **Nimble reads only what you can open**.

## If it doesn't work

- **This question needs an AI model**: only counts, lists and lookups run without one. A tenant admin can register one: see [Choose the AI model](./ai-model.mdx).
- **I didn't find any matching data**, or **That's outside what I can answer from your graph**: the graph does not hold it, or it is not linked. Add the data ([Bring in an outside data source](./outside-source.mdx)) or check [Data health](./data-health.mdx).
- **Held back**: a check rejected the answer, and the message says why. Ask again with a narrower question.
- **The answer did not arrive here**: your sign-in expired while Nimble worked. Reload the conversation. The answer is saved.
