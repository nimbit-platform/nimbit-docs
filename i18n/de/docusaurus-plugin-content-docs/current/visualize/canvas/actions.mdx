Lassen Sie Benutzer aus der Zeichnung heraus handeln: eine Pumpe starten, das Detail-Canvas einer Maschine öffnen, zu einem anderen Thing wechseln. Sie legen das im Tab **Aktion** eines Elements fest. Wie Aktionen ins Bild passen, erklärt [Wie ein Canvas funktioniert](./how-canvas-works.mdx).

## Bevor Sie beginnen {#before-you-start}
- Eine Rolle, die Canvases aktualisieren darf.
- Für einen Befehl: eine Aktion am Thing oder Thing-Typ, aktiv, mit eingeschaltetem **Verwendung als Dashboard-Widget zulassen**. Ist die Auswahl leer, legen Sie die Aktion zuerst an oder ändern Sie sie. Das Panel bietet an, die Aktion für das Thing oder den Typ zu erstellen (**Aktion für … erstellen**).
- Bedienung für das Canvas erlaubt, siehe Schritt 1.

## Schritte {#steps}

1. Wählen Sie **Canvas-Einstellungen** und schalten Sie **Bedienung erlauben** ein. Ohne sie zeigen Aktionselemente **Bedienung ist für dieses Canvas ausgeschaltet** und sind deaktiviert.
2. Wählen Sie **Canvas Bearbeiten** und dann eine **Schaltfläche**, einen **Schalter**, einen **Sollwert**, einen **Hotspot** oder ein R&I-Symbol. Andere Elemente haben keinen Tab **Aktion**.
3. Öffnen Sie den Tab **Aktion**. Wählen Sie unter **Beim Klick** eine **Art**:
   - **Aktion ausführen**: Wählen Sie **Aktion auswählen** und das **Ziel**-Thing.
   - **Navigation**: ein anderes Canvas oder einen Link öffnen.
   - **Kontext-Thing wechseln**: das Thing ändern, das das Canvas zeigt.
   - **Variable setzen**: eine Variable des Canvas setzen.
   - **Keine**: nichts.
4. Setzen Sie bei **Aktion ausführen** die Sicherungen, die Sie brauchen:
   - **Bestätigung**, einschließlich einer getippten Bestätigung für **Kritisches Anlagenteil**.
   - **Nur aktiv, wenn** ein Live-Wert es erlaubt. Sonst ist die Schaltfläche deaktiviert und nennt den Grund. Dafür muss im Tab **Daten** ein Wert gebunden sein.
   - **Erwartetes Ergebnis** und **Innerhalb**: Das Canvas wartet auf einen Wert, der bestätigt, dass die Aktion gewirkt hat, und meldet es, wenn nicht.
   - **Sperrzeit** zwischen zwei Ausführungen.
   - **Folge**: ein Hinweis, was beim Ausführen geschieht.
   - **Gesendeter Wert**: ein optionaler Wert in der Payload, zum Beispiel eine Schalterstellung. Ein **Sollwert** sendet den Wert, der in der Ansicht gesetzt wurde.
5. Wählen Sie **Vorschau**. Befehle in der Vorschau sind Probeläufe: Der Dialog meldet **Vorschau: Dies ist ein Probelauf, es wird nichts gesendet.**
6. Wählen Sie **Speichern**.

## Prüfen, ob es geklappt hat {#check-that-it-worked}

Öffnen Sie das Canvas als Betrachter, der das Thing bedienen darf, und wählen Sie das Element. Ein Bestätigungsdialog nennt die Aktion und das Thing. Nach Ihrer Bestätigung zeigt das Element das Ergebnis: **Von … bestätigt** mit dem Thing und der Zeit, oder **Gesendet**, wenn Sie kein erwartetes Ergebnis festgelegt haben und nichts zurückgemeldet wird.

## Wenn es nicht funktioniert {#if-it-doesnt-work}

- **Bedienung ist für dieses Canvas ausgeschaltet**: Schalten Sie **Bedienung erlauben** in den **Canvas-Einstellungen** ein.
- **Fehlerhaft: Aktion nicht gefunden**: Das Thing oder sein Typ hat diese Aktion nicht. Wählen Sie eine andere Aktion oder fügen Sie sie dem Thing-Typ hinzu.
- **Sie dürfen … nicht bedienen**: Die eigenen Berechtigungen der Aktion entscheiden. Bitten Sie Ihren Administrator um die Rolle, die sie nennt.
- **Bedienung pausiert, solange ein vergangener Zeitraum angezeigt wird**: Schalten Sie die Kopfzeile auf einen Live-Zeitraum.
- **Zum Bedienen die ganze Seite öffnen** oder **Canvas zum Bedienen öffnen**: Sie sind in einem Seitenpanel oder einer Einbettung. Öffnen Sie das Canvas selbst.
- **Variablen setzen wird noch nicht unterstützt**: Der Ort, der das Canvas zeigt, unterstützt keine Variablen. {/* TODO(product): How does an editor create a canvas variable, and where is Set a variable supported? */}
