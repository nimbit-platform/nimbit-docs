Jedes Werkzeug, Element und jede Option des Canvas-Editors, so benannt wie in der App. Aufgaben beginnen bei [Canvas](./index.mdx).

## Ein Canvas anlegen {#create-a-canvas}

| Feld | Werte | Bedeutung |
| --- | --- | --- |
| **Name** | Text | Pflichtfeld. |
| **Interfaces** | Interfaces | Betrachter wählen ein Kontext-Thing, das sie umsetzt. Leer: Jedes Element ist an ein festes Thing gebunden. |
| **Ausgangspunkt** | **Leeres Canvas**, **Aus Bild**, **Aus R&I-Fließbild**, **Aus Vorlage** | **Aus R&I-Fließbild** ordnet die Kennzeichen der Zeichnung Things zu (Beta). Eine Vorlage wird **von Nimbit verwaltet** oder **als Kopie zum freien Ändern** hinzugefügt. |

## Werkzeugleiste {#toolbar}

| Werkzeug | Taste | Funktion |
| --- | --- | --- |
| **Auswahlwerkzeug** | <kbd>V</kbd> | Auswählen und verschieben. |
| **Handwerkzeug** | <kbd>H</kbd> | Verschieben der Ansicht. |
| **Stift** | <kbd>P</kbd> | Freihandstrich. |
| **Linie** | <kbd>L</kbd> | Gerade Linie. |
| **Pfeil** | <kbd>Umschalt</kbd>+<kbd>L</kbd> | Linie mit Spitze. |
| **Rechteck** | <kbd>R</kbd> | Rechteck. |
| **Ellipse** | <kbd>O</kbd> | Ellipse. |
| **Zone** | <kbd>Z</kbd> | Polygonfläche. |
| **Hotspot von Hand** | keine | Einen anklickbaren Bereich zeichnen. |
| **Rohrleitung** | <kbd>C</kbd> | Anlagen verbinden. |
| **Einrasten**, **Raster** | keine | Elemente ausrichten. |
| Text, Notiz | <kbd>T</kbd>, <kbd>N</kbd> | Einen **Text** oder eine **Notiz** hinzufügen. |
| Vergrößern, Verkleinern | <kbd>+</kbd>, <kbd>-</kbd> | Zoomen. **Zoom zurücksetzen** und **Auf Inhalt zentrieren** stehen im Zoommenü. |

<kbd>A</kbd> öffnet die Elementsuche. <kbd>Strg</kbd>+<kbd>Z</kbd> macht rückgängig. Tasten werden ignoriert, während Sie in ein Feld tippen. Im Editor verschiebt <kbd>Leertaste</kbd> + Ziehen die Ansicht, Umschalt-Klick erweitert die Auswahl, und Ziehen auf dem Hintergrund wählt mehrere aus.

## Elemente {#elements}

| Abschnitt | Elemente |
| --- | --- |
| **Daten** | **Wert**, **KPI**, **Gauge**, **Lineares Gauge**, **Füllstand**, **Diagramm**, **Kompaktes Diagramm**, **Sparkline**, **Zustands-Badge**, **Zustands-Icon**, **Zustandsverlauf**, **Thing-Karte**, **Sammelwert** |
| **Bedienelemente** | **Schaltfläche**, **Schalter**, **Sollwert**, **Hotspot** |
| **Zeichnen & Grundformen** | **Text**, **Notiz**, **Form**, **Linie**, **Zone**, **Bild** |
| **Einbettungen** | **Dashboard-Widget**, **Canvas**, **Webseite**, **VNC-Konsole** |
| **R&I-Symbole** | **Tank**, Pumpen, Ventile und andere Prozesssymbole |

Wert-, Diagramm- und Thing-Karten-Elemente haben eine Einstellung **Anzeige**: **Canvas-Standard**, **Voll**, **Kompakt**, **Automatisch** oder **Werte-Kachel, Diagramm beim Überfahren**. Kompakt wechselt auf dem Bildschirm unter 96 × 72 px zu einem Wert-Chip.

## Inspektor {#inspector}

Wählen Sie ein Element, um seine Tabs zu sehen. Ist nichts ausgewählt: *Wählen Sie ein Element aus, um seine Eigenschaften zu bearbeiten.*

| Tab | Legt fest |
| --- | --- |
| **Daten** | Woher der Wert kommt. |
| **Darstellung** | Aussehen, Position und Größe, **Ausrichten** und **Verteilen**. |
| **Zustände** | Regeln, die das Aussehen mit dem Wert ändern. |
| **Aktion** | Was ein Klick bewirkt. Nur bei Schaltflächen, Symbolen, Hotspots, Schaltern und Sollwerten. |

### Datenoptionen {#data-options}

| Option | Werte | Bedeutung |
| --- | --- | --- |
| **Quelle** | **Aus dem Kontext**, **Festes Thing** | Das Thing des Betrachters oder ein Gerät. |
| **Wert binden** | Thing, Telemetrie oder Eigenschaft | Durchsuchbar. Bei Text auch Datums- und Zeitwerte: **Datum & Uhrzeit**, **Datum**, **Uhrzeit**, **Wochentag**, **Monat**, **Jahr**. |
| **Schwellenwerte** | **Gleich**, **Größer als**, **Größer oder gleich**, **Kleiner als**, **Kleiner oder gleich**, **Bereich** | Mit einem Wert oder **Minimalwert** und **Maximalwert**, einem **Hintergrund** und einer **Textfarbe**. |
| **Daten als veraltet betrachten nach** | Dauer | Je Element. Der Standard ist der des Canvas. |

### Zustandsoptionen {#state-options}

| Option | Werte |
| --- | --- |
| **Zustand aus** | Der gebundene Wert, live angezeigt. |
| **Wenn** | Operator und Wert. **Sonst wenn** fügt eine Regel hinzu, **Sonst** ist die Rückfallregel. |
| **Zustand** | Ein Name, etwa `running` oder `high alarm`. |
| **Schweregrad** | **Automatisch**, **Normal**, **Info**, **Warnung**, **Alarm**, **Störung**. Wird als **Veraltet** oder **Unbekannt** angezeigt, wenn kein aktueller Wert vorliegt. |
| **Farbe** | Jede Farbe. Ohne sie nutzen Warnung, Alarm und Störung die Farbe ihres Schweregrads. |
| **Icon**, **Bewegung** | Für Icon-Elemente. Bewegung: **Blinken**, **Uhr**, **Drehen**, **Keine Bewegung**. |
| **Gilt für** | Textelemente: **Ganzen Text** oder **Nur diesen Wert**. |

Zustände eines **Zustandsverlaufs** nutzen **Gleich**, **Unter**, **Zwischen** oder **Ab**.

### Aktionsarten {#action-types}

| Art | Was geschieht |
| --- | --- |
| **Aktion ausführen** | Führt eine Aktion des Things auf dem **Ziel**-Thing aus. |
| **Navigation** | Öffnet ein anderes Canvas oder einen Link. |
| **Kontext-Thing wechseln** | Ändert das Thing, das das Canvas zeigt. |
| **Variable setzen** | Setzt eine Canvas-Variable. Meldet *Variablen setzen wird noch nicht unterstützt*, wo es nicht unterstützt wird. |
| **Keine** | Nichts. |

Sicherungen für **Aktion ausführen**: **Bestätigung**, **Kritisches Anlagenteil** (getippte Bestätigung), **Nur aktiv, wenn**, **Erwartetes Ergebnis** mit **Innerhalb**, **Sperrzeit**, **Folge**, **Gesendeter Wert**, **Beschriftung** und **Weitere Aktionen** (neben der Hauptaktion angezeigt).

## Rohrleitungen {#pipes}

Eine Rohrleitung oder **Signalleitung** verbindet zwei Elemente. Wählen Sie sie, um **Beschriftung**, **Leitungsart**, **Verlauf** und ihre **Daten**-Werte zu setzen. Eine Beschriftung kann mit `{{value1}}` einen Live-Wert zeigen, wobei `value1` ein Wert aus dem Tab **Daten** ist. Ziehen Sie einen Knick, um ihn zu verschieben, doppelklicken Sie auf die Linie, um einen hinzuzufügen, und doppelklicken Sie auf einen Knick oder drücken Sie <kbd>Entf</kbd>, um ihn zu entfernen. Bei einer neuen Rohrleitung ist die **Flussrichtung nicht bestätigt**, bis Sie sie **Bestätigen** oder **Umkehren**. Bis dahin bleibt sie aus dem Anlagengraphen heraus.

## Ebenen und Anordnen {#layers-and-arranging}

| Wo | Bietet |
| --- | --- |
| **Ebenen** | Jedes Element in Zeichenreihenfolge. Umbenennen, **Ausblenden**, **Sperren**. Elemente auf einem Bild hängen darunter. **Rohrleitungen** stehen getrennt. |
| Auswahlleiste | Ausrichten, verteilen, gruppieren, duplizieren, sperren. |
| Rechtsklick | **In den Vordergrund**, **Eine Ebene nach vorne**, **Eine Ebene nach hinten**, **In den Hintergrund**, **Kopieren**, **Einfügen**, **Duplizieren**, **Gruppieren**, **Sperren** oder **Entsperren**, **Löschen**. |

## Canvas-Einstellungen {#canvas-settings}

| Einstellung | Bedeutung |
| --- | --- |
| **Name**, **Beschreibung** | Kennzeichnen das Canvas. |
| **Art** | Sortiert das Canvas in die Filter der Liste. |
| **Interfaces** | Die Interfaces, aus denen Betrachter ein Kontext-Thing wählen. |
| **Theme** | Das Theme des Canvas. |
| **Standardzeitraum** | Der Zeitraum, mit dem ein Betrachter beginnt. |
| **Bedienung erlauben** | Lässt Schaltflächen, Schalter, Sollwerte und Ventilaktionen Befehle senden. Aktionsberechtigungen gelten weiterhin. |
| **Kompakt beim Herauszoomen** | Legt fest, wie Elemente auf **Canvas-Standard** schrumpfen. |
| **Daten als veraltet betrachten nach** | Standard für das ganze Canvas. |
| **Anlagengraph** | Ist er für den Tenant aktiviert, können gespeicherte Rohrleitungen den Anlagengraphen aktualisieren. |

## Speichern, Vorschau und verwaltete Canvases {#save-preview-and-managed-canvases}

| Eintrag | Bedeutung |
| --- | --- |
| **Vorschau** | Zeigt das Canvas, wie Betrachter es sehen, in beiden Themes. Befehle sind Probeläufe. **Vorschau beenden** kehrt zum Bearbeiten zurück. |
| Status | **Nicht gespeichert**, **Wird gespeichert…**, **Gespeichert**, **Konflikt**. |
| **Speichern**, **Speichern und beenden**, **Als Kopie speichern** | Veröffentlichen, veröffentlichen und verlassen oder Ihre Arbeit nach einem Konflikt als neues Canvas behalten. |
| **Von Nimbit verwaltet** | **Auf Version … aktualisieren** übernimmt eine neue Vorlagenversion. **Auf Nimbit-Version zurücksetzen** verwirft Ihre Änderungen. **Duplizieren** erzeugt eine Kopie, die Nimbit nicht mehr aktualisiert. |

## Betrachter {#viewer}

| Eintrag | Bedeutung |
| --- | --- |
| Thing-Auswahl | Wählt das Kontext-Thing. Der Link, den Sie teilen, behält die Auswahl. |
| Zeitraum | Ein vergangener Zeitraum zeigt den Verlauf. **Live** kehrt zur Gegenwart zurück. |
| Alarm-Chip | Listet Alarme und veraltete Werte. Wählen Sie ihn für den nächsten. |
| Zoom | Ziehen verschiebt die Ansicht, Scrollen oder Strg+Scrollen zoomt. |
