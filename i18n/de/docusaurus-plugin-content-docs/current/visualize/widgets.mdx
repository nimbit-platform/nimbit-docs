Ein Widget ist eine Kachel auf einem Dashboard. Der Dialog **Widget hinzufügen** gruppiert Widgets nach der Frage, die sie beantworten. Diese Seite folgt denselben Gruppen. Wählen Sie **Bearbeiten** und dann **Widget hinzufügen**, richten Sie es bei laufender Live-Vorschau ein, wählen Sie **Zum Dashboard hinzufügen** und speichern Sie das Dashboard. **Hilfe** in der Einrichtung erklärt die Einstellungen in der App. Den ganzen Ablauf beschreibt [Ein Dashboard für ein Thing bauen](./thing-dashboard.mdx).

Drei Dinge gelten für jedes Widget:

- **Titel** und **Darstellung** (oder **Karte**): ein Titel und Farben, wo das Widget eine Karte zeichnet. Sie werden in den Tabellen unten nicht wiederholt.
- **Zeitraum**: Widgets, die Daten über die Zeit lesen, folgen dem Zeitraum des Dashboards, sofern Sie ihn im Widget nicht überschreiben. Siehe [Dashboards, Smart-Dashboards und Zeit](./dashboards.mdx).
- **Verfügbar auf**: Die Auswahl zeigt nur Widgets, die zum bearbeiteten Dashboard passen. Widgets, die **ein Thing lesen**, brauchen ein Thing im Kontext: das eigene Thing des Dashboards oder eines, das Sie im Widget wählen. Folgen und Anheften beschreibt [Ein Dashboard für alle Things einer Art bauen](./smart-dashboard.mdx). Widgets für den ganzen Tenant gehören auf Home und andere Dashboards für den ganzen Tenant.

## Welches Widget für welche Frage {#which-widget-for-which-question}

| Frage | Gruppe | Widgets |

| Was liest es gerade? | [Werte](#values) | Momentaufnahme, Gauge, Füllstand, Vergleichen |
| Läuft es, ist es offen, an? | [Zustand](#state) | Messwert, Boolean, Eigenschaft, Liste der Eigenschaften, Aggregierter Zustand |
| Wie hat es sich verändert? | [Diagramme](#charts) | Diagramm, Zeitachse, Heatmap, Donut, Pivot-Tabelle, Benutzerdefiniert |
| Was tut es, und was kann ich tun? | [Thing-Details](#thing-details) | Status, Aktion, Canvas |
| Was ist passiert, und was hat ausgelöst? | [Events und Regeln](#events-and-rules) | Events, Vorfälle, Event-Statistiken |
| Wie geht es dem Tenant? | [Überblick](#overview) | Zählerleiste, Zähler, Health-Score |
| Kommen Daten an? | [Nachrichten](#messages) | Nachrichten-Statistiken |
| Welche Things sind offline? | [Verbindung](#connectivity) | Verbindungsstatistiken, Thing-Karte, Thing-Liste & Karte |
| Wo liegen die Daten, und wer erreicht sie? | [Daten und Zugriff](#data-and-access) | Datenspeicher, Statistiken zu API-Schlüsseln und Speicher |
| Wie gliedere und erkläre ich das Dashboard? | [Layout und Inhalt](#layout-and-content) | Abschnittsüberschrift, Text, Bild, Dateiliste, Container, Iframe, Karte und weitere |

## Werte {#values}

Was liest es gerade?

### Momentaufnahme {#snapshot}

**Zeigt:** Die letzten Werte der Telemetrien eines Things in einer durchsuchbaren Tabelle: Telemetriename, letzter Wert mit Einheit und Zeit.

**Nutzen, wenn:** Sie jeden aktuellen Messwert eines Things an einer Stelle sehen möchten.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

| Einstellung | Was sie bewirkt |
| --- | --- |
| **Thing / Telemetrien** | Welches Thing gelesen wird, auf einem Dashboard, das keinem folgt. |
| **Suche** | Filtert die Zeilen nach Telemetriename (in der Ansicht). |

Numerische Zeilen zeigen beim Überfahren ein Diagramm-Icon, das eine Abfrage für diese Telemetrie öffnet. Das Widget unterstützt den Vollbildmodus für lange Listen.

### Gauge {#gauge}

**Zeigt:** Eine Telemetrie auf einer Skala, mit ihrem Bereich.

**Nutzen, wenn:** Es darauf ankommt, wo ein Wert zwischen Minimum und Maximum liegt, etwa bei Druck oder Last.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

| **Telemetrie** | Die Telemetrie, die gezeigt wird. Pflichtfeld. |

| **Shape** | Breiter oder schmaler Bogen. |
| **Schwellenwerte** | Farbzonen für Wertebereiche. |
| **Gradient** | Weiche Farbübergänge zwischen Zonen. |
| **Icon**, **Kompakte Zahl**, **Schriftgröße** | Wie der Wert gezeichnet wird. |

### Füllstand {#fill-level}

**Zeigt:** Wie voll ein Tank oder Silo ist, als Füllbalken.

**Nutzen, wenn:** Die Telemetrie ein Füllstand ist und wichtig ist, wie voll es ist, nicht die Zahl.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

**Zeigt:** Zwei Werte nebeneinander, mit der Differenz.

**Nutzen, wenn:** Sie einen Wert mit einem früheren vergleichen oder eine Kennzahl wie Durchschnitt, Summe oder Spitze über einen Zeitraum brauchen.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

| **Zeitraum** | Der Zeitraum, den der Wert abdeckt. |
| **Kompakte Zahl** | Große Werte kürzen, zum Beispiel 1,2 k. |
| **Ausrichtung**, **Schriftgröße** | Wie der Wert gezeichnet wird. |

## Zustand {#state}

**Nutzen, wenn:** Sie eine große, auf einen Blick lesbare Zahl möchten, die die Farbe wechselt, wenn sie ihren Normalbereich verlässt.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

## Diagramme {#charts}

Wie hat es sich verändert?

### Diagramm {#chart}

**Zeigt:** Telemetrien über die Zeit. Wählen Sie ein Layout: **Linie**, **Fläche**, **Balken**, **Streuung** oder **Kombination** (Balken und Linien in einem Diagramm). Das Layout können Sie später in den Einstellungen des Widgets ändern.

**Nutzen, wenn:** Sie Trends ansehen, Telemetrien vergleichen oder einen Wert gegen eine Grenze prüfen.

**Verfügbar auf:** Liest ein Thing. Auf einem Smart-Dashboard folgt es dem gewählten Thing oder ist an ein eigenes Thing angeheftet.

| **Berechnete Reihe hinzufügen** | Eine Zeile, die mit einer Formel aus Messwerten berechnet wird. Siehe [Einem Diagramm eine berechnete Reihe hinzufügen](./calculated-series.mdx). |

## Events und Regeln {#events-and-rules}

Was ist passiert, und was hat ausgelöst?

### Events {#events}

**Zeigt:** Die Events des Dashboards: auf einem Dashboard für den ganzen Tenant jedes Event des Tenants, sonst die Events seiner Things. Eine Zeile je Event, das neueste zuerst.

**Nutzen, wenn:** Sie den jüngsten Verlauf dessen sehen möchten, was ausgelöst hat, mit Schweregrad und Typ.

**Verfügbar auf:** Jedes Dashboard. Auf einem Dashboard zu einem Thing listet die Auswahl es unter **Thing-Details**.

<Screenshot
  page="visualize/widgets"
  id="19-events"
  route="/dashboards/:id"
  state="Events list with severity chips and five rows"
  alt="Das Widget Events auf einem Dashboard"
/>

| Einstellung | Was sie bewirkt |
| --- | --- |
| **Event Typen** | Ein oder mehrere Typen, die gezeigt werden. Leer bedeutet alle. |
| **Zeitraum** | Folgt dem Dashboard, sofern Sie ihn nicht überschreiben. |

Chips filtern nach Schweregrad und zeigen Anzahlen. **Event-Explorer öffnen** öffnet die Seite Events mit demselben Filter.

### Vorfälle {#incidents}

**Zeigt:** Die Probleme, an denen jemand arbeitet, die neueste Aktivität zuerst, mit Schweregrad, Nummer, wer sie eröffnet hat, und Status.

**Nutzen, wenn:** Benutzer sehen sollen, was jetzt Aufmerksamkeit braucht.

**Verfügbar auf:** Jedes Dashboard außer Berichten. Auf einem Dashboard zu einem Thing listet die Auswahl es unter **Thing-Details**.

<Screenshot

| Einstellung | Was sie bewirkt |
| --- | --- |
| **Titel** | Wird über der Liste gezeigt. |
| **Zeigt zuerst** | Mit aktiven Vorfällen oder mit allen beginnen. |
| **Zeilen** | 5, 10 oder 20 vor **Alle Vorfälle**. |
| **Karte** | Hintergrund- und Rahmenfarben. |

Nur Mitglieder, die Vorfälle lesen dürfen, sehen es.

### Event-Statistiken {#event-statistics}

## Statistiken {#statistics}

Die Statistikkarten (Event-Statistiken, **Health-Score**, **Nachrichten**, Verbindungsstatistiken und Statistiken zu Daten und Zugriff) sind ein Widget-Typ, **Statistik**, mit einer Vorgabe je Karte. Sie brauchen keine Dateneinrichtung: Wählen Sie die Karte, und sie funktioniert. Nachrichtenzahlen stammen aus Plattformmetriken, die gebündelt eintreffen und bis zu 5 Minuten nachlaufen können. Ein Betrachter, dessen Rolle keine Metriken abfragen darf, sieht statt der Zahlen einen Hinweis.
