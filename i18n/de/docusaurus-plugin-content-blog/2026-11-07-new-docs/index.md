Wir haben die IoT-Breeze-Doku von Grund auf neu geschrieben. Sie ist nach dem gegliedert, was Sie erledigen wollen, passt zur aktuellen App und ist jetzt auch auf Deutsch verfügbar.

<!-- truncate -->

## Die Seite für Ihre Aufgabe finden

Die Doku folgt Ihren Daten, vom Gerät zur Entscheidung. Jeder Bereich beantwortet eine Frage:

| Bereich | Frage |
| --- | --- |
| [Geräte verbinden](/docs/connect) | Wie kommen meine Daten rein? |
| [Gateways und Edge](/docs/gateways) | Wie binde ich Maschinen an? |
| [Daten modellieren](/docs/model) | Wie beschreibe ich meine Geräte? |
| [Visualisieren](/docs/visualize) | Wie sehe ich meine Daten? |
| [Überwachen und reagieren](/docs/watch) | Was braucht mich gerade? |
| [Automatisieren](/docs/automate) | Was erledigt es für mich? |
| [Knowledge und KI](/docs/knowledge) | Was kann ich fragen? |
| [Verwalten](/docs/administer) | Wer darf was? |
| [Fehlerbehebung](/docs/troubleshooting) | Etwas stimmt nicht. |

Jede Seite hat eine Aufgabe. Ein Tutorial lehrt durch Tun, eine Anleitung erledigt eine Aufgabe, ein Konzept erklärt, wie etwas funktioniert, und eine Referenz listet jedes Feld. Die Markierung oben auf jeder Seite zeigt, welche Art Sie gerade lesen.

Neu bei IoT Breeze? Der [Quickstart](/docs/get-started/quickstart) führt Sie in etwa 15 Minuten von einem simulierten Gerät zu einem Dashboard und einem Alarm, ohne Hardware. Wenn Sie Ihre Rolle kennen, [starten Sie dort](/docs/get-started): Betrieb, Lösungsbau, Entwicklung oder Administration.

## Geführte Touren aus der Doku starten

IoT Breeze hat geführte Touren, die Sie Schritt für Schritt durch einen Bildschirm führen. Seiten mit einer passenden Tour verlinken sie jetzt: Wählen Sie die Karte, und die Tour startet in Ihrem IoT Breeze. Alle Touren stehen unter [Geführte Touren](/docs/get-started/guided-tours).

## Links, die Ihr IoT Breeze öffnen

Läuft Ihr IoT Breeze auf Ihrer eigenen Domain, öffnen Sie oben in der Doku den Pfeil neben **IoT Breeze öffnen** und geben Sie Ihre Adresse einmal ein. Links aus der Doku in die App und geführte Touren öffnen sich dann dort.

## Auf Deutsch

Jede Seite gibt es auf Deutsch. Die Sprache wechseln Sie oben. Die deutschen Seiten verwenden die Beschriftungen, die das deutsche IoT Breeze zeigt: Was Sie lesen, sehen Sie auch auf dem Bildschirm.
