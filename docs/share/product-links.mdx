A product link is a web address printed on a product, usually as a QR code. It opens a public page with the fields and documents you publish for that thing or thing type, and nothing else.

:::warning A product link is not secret
It is printed on the product, so anyone who sees the product can open it. Publish only what you want public.
:::

## Before you start

- A tenant admin has switched on **Asset Administration Shell** and **Product links** under **Administration › Tenant Settings › Features**. Product links stay off while the AAS feature is off.
- For a thing's link, the thing is exposed as an Asset Administration Shell; see [Publish things as Asset Administration Shells](./asset-administration-shell.mdx). Otherwise the link shows nothing, and the tab says so.
- Seeing links, published fields and the preview needs the **Passport** read permission: **Admin**, **System Admin** and **Manager** have it. Creating and changing links, and publishing, needs the **Passport** update permission: **Admin** and **System Admin**.
- API keys cannot manage product links.

## Create a link and choose what it shows

1. Open the thing, or the thing type under **Settings › Onboarding › Thing Types**, and select the **Product link** tab.
2. Select **Create product link**. The link starts as **Not public yet**: it shows nothing to anyone until you activate it.
3. Under **Fields**, publish fields on the thing type. Select **Publish** on a field, and under **Value** choose **The type's value** or **Each Thing's own value**. A thing type's own link shows only fields with the type's value.
4. On a single thing, the fields are those published on its type. To keep one off this thing's page, turn off **Show on this Thing**. The field then shows **Hidden on this Thing**.
5. Under **Documents**, select **Publish** for each document to show. Visitors can download it.

Some fields can never be published, and the tab marks them:
- **Private: cannot be published**: a field declared private on the type, or one whose value a private field reads through a proxy.
- **Device-reported: cannot be published**: a value the device reports.

## Preview and activate

1. Check the **Preview** on the tab, or select **Open page preview** to see the full page. A banner says whether the page is public. Documents are listed in the preview but cannot be opened there.
2. Select **Activate**, and confirm **Make this product link public?**. From now on anyone with the link, or who scans its code, sees the page from the preview.

The QR code and **Print label** appear once the link is active.

## Print a label

1. Select **Print label**.
2. Choose a **Label size**: **Small**, **Medium** or **Large**. Optionally enter a **Caption**.
3. Select **Print**. Print at actual size (100 %), or save as PDF. The label shows the QR code and the link as text.

Labels exist only for an active link.

## Suspend, resume or retire

| Action | Effect |
| --- | --- |
| **Suspend** | The page shows nothing until you select **Resume**. Printed codes keep their address. |
| **Retire** | Final. The link shows nothing, can never be used again, and its printed codes stop working. **Create new link** makes a link with a new address, so you print new codes. |

After you retire a link, the tab keeps showing it as **Retired**, so you can see why printed codes no longer work.

## What visitors see

Visitors see the published fields (label, value and unit), the published documents, and when the page was last updated. They never see the thing's or type's name or id, unpublished or private fields, file paths, or anything else of your tenant.

Every hidden state gets the same "not found" page: an unknown, not yet public, suspended or retired link, a feature switched off, a thing no longer exposed, or nothing published. A visitor cannot tell them apart. Pages are marked for search engines not to index them, and visitors' personal data is not recorded.

## Limits

- **Busy**: when too many requests arrive, visitors see "Too many requests right now" and can try again a moment later.
- **Changes**: publishing, hiding, suspending and retiring take effect at once. A changed value of a published field shows within about a minute.
- **Documents**: up to 50 MB each. PDF, PNG, JPEG and WebP open in the browser. Other types download.
- **One link address per installation.**
- **Logs**: IoT Breeze logs only the first 6 characters of a link's token.
