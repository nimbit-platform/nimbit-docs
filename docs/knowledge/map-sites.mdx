Build the tree of sites, plants, halls and lines, then put things in it. Explore and Ask Nimble use the tree to answer questions about a place. For what a level is, read [The knowledge graph](./knowledge-graph.mdx).

## Before you start

- You need permission to edit Knowledge, and **Ask Nimble and Knowledge** turned on for the tenant (see [Knowledge and AI](./index.mdx)).
- A type with the **Hierarchical** trait must exist to use as a level. If **Add site** says **Create a level type first**, create one in **Settings › Knowledge setup › Data model › Types** and tick the **Hierarchical** and **Describable** traits. See [Types and traits](./types-and-traits.mdx).

## Add the levels

1. Open **Knowledge › Explore** and stay on the **Hierarchy** view.
2. Select **Add site** above the tree and name it.
3. Open the site's menu and choose **Add level below** to add a hall. Repeat for lines or rooms.

To rename or move a level, use its menu, or drag it onto another level. Everything below it moves too. A level moves only within its own type.

## Place things

1. Select a level, open the **Things** tab and choose **Add things…**.
2. Tick the things that sit here and add them. A thing placed elsewhere moves here.

To place many things at once, open the **Table** view, select the things and choose **Place in level…**.

## Attach dashboards and documents

- On the **Visualizations** tab, select **Assign** to attach an existing dashboard or canvas, or create a new smart dashboard for the level. See [Build one dashboard for every thing of a kind](../visualize/smart-dashboard.mdx).
- On the **Documents** tab, select **Add documents**, or attach a file that is already in Files. Documents you add are stored in a folder in Files that everyone in the tenant can open. See [Store and share files](../administer/files.mdx).

## Relate records and set access

- To link two records, open one and add a relation on its **Relations** tab. Pick a relation the type declares.
- To control who sees a governed record such as an asset, open it and use its **Access** panel to add groups or users.

## Check that it worked

Select the level. The **Insights** tab shows its things, their connectivity and recent events, and **Things that need a look** lists offline or silent ones. Ask Nimble "What is in Hall 2?" and the answer names the things you placed.

## If it doesn't work

- **Add site says Create a level type first**: no type has the **Hierarchical** trait. Create one first.
- **A thing is not listed under its level**: it was placed at another level. A record sits at one level. Add it again here to move it.
- **Questions about a hall find nothing**: the things are not placed in it, or have no location. Run **Check now** under [Data health](./data-health.mdx) and look at **Records without a location**.
