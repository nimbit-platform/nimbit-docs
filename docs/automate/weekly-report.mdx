Build a report of the last seven days that IoT Breeze renders to PDF every week, saves in a folder and sends to your subscribers. Every field is described in [Report settings](./report-settings.mdx).

## Before you start

- A role that may create and update reports, and a desktop browser. The report editor does not open on a phone.
- Things that have data in the period you want to report on.
- For email delivery, a mail server set up for your tenant. Without one, subscribers can still get an in-app notification.

## Create the report

1. Open **Settings › Automation › Reports** and select **Create report**.
2. Enter a unique **Name**, for example `Weekly overview`.
3. Under **File settings**, enter the **File name**. Press `@` and choose a date value, so each week's PDF gets its own name. Select the **Folder** button, pick a folder, and select **Select this folder**.
4. Under **Things**, choose the things the report covers.
5. Under **Schedule**, set **Start date** and **Start time** to the first run. Leave **Timeframe** on **Last 7 days**. Under **Recurrence**, set **Repeat every** to `1` and **Week**.
6. Save. The report appears in the list as not published.

## Design the report

1. Select the report name to open the editor.
2. Select the pencil to enter edit mode. Add widgets from the panel on the left, or select **+** to use the widget wizard. Each widget is set up as on a dashboard. See [Widget gallery](../visualize/widgets.mdx).
3. Drag widgets into place. Select **Add page** for more pages, and **Canvas size** to choose **A4 Portrait**, **A4 Landscape** or a custom size.
4. Select the pencil again to save. The header shows **Saved**.

## Add subscribers

1. Select **Subscriptions** in the editor header, then **Add user**.
2. Pick a user, or enter an **External** email address for someone without an account.
3. Choose **Send mail**, **Send notification**, or both. External addresses receive mail only.

## Publish and test

1. Select **Publish**. The button now reads **Unpublish**. The schedule runs from the start date and time you set.
2. To test now, select **Generate**, choose a time range, and select **Generate and send**. The button then waits 30 seconds before you can use it again.

## Check that it worked

After about 30 seconds the PDF is in the folder you chose, which you can open in the file explorer. Subscribers receive the mail or notification. Open the schedule icon in the report list to see when the last report was created and when the next is due.

## If it doesn't work

- **Publish is refused: the timeframe is not fully defined**: open the report settings with the gear and fill in **Start date**, **Start time** and **Repeat every**.
- **A warning says no mail server is configured**: subscriptions are not sent as email. Choose **Send notification**, or ask your administrator to set up a mail server in [Tenant settings](../administer/tenant-settings.mdx).
- **The PDF is not in the folder**: wait the full 30 seconds, then check the exact folder chosen under **File settings**.
- **The PDF covers the wrong period**: the **Timeframe** is relative to the moment the run starts. Change it in the report settings.
