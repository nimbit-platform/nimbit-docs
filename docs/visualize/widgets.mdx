A widget is one tile on a dashboard. The **Add widget** dialog groups widgets by the question they answer; this page follows the same groups. Select **Edit**, then **Add widget**, set it up while the live preview updates, then select **Add to dashboard** and save the dashboard. **Help** in the setup explains the settings in the app. For the whole flow, see [Build a dashboard for one thing](./thing-dashboard.mdx).

Three things apply to every widget:

- **Title** and **Appearance** (or **Card**) settings: a title, and colors where the widget draws a card. They are not repeated in the tables below.
- **Time range**: widgets that read data over time follow the dashboard's time range unless you override it in the widget. See [Dashboards, smart dashboards and time](./dashboards.mdx).
- **Offered on**: the picker shows only the widgets that fit the dashboard you edit. Widgets that **read a thing** need a thing in context: the dashboard's own thing, or one you choose in the widget. See [Build one dashboard for every thing of a kind](./smart-dashboard.mdx) for follow and pin. Tenant-wide widgets belong on Home and other tenant-wide dashboards.

## Values

What does it read right now?

### Snapshot

**Shows:** The latest values of a thing's measures in a searchable table: measure name, last value with unit, and time.

**Use it when:** You want every current reading of a thing in one place.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

| Setting | What it does |
| --- | --- |
| **Thing / measures** | Which thing to read, on a dashboard that does not follow one. |
| **Search** | Filter the rows by measure name (when viewing). |

Numeric rows show a chart icon on hover that opens a query for that measure. The widget supports full screen for long lists.

### Gauge

**Shows:** One measure on a dial, with its range.

**Use it when:** You care where a value sits between a minimum and a maximum, such as pressure or load.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

<Screenshot

| Setting | What it does |
| --- | --- |
| **Measure** | The measure to show. Required. |
| **Min / Max** | The range of the dial. Required. |
| **Shape** | Wide or narrow arc. |
| **Thresholds** | Color zones for value ranges. |
| **Gradient** | Smooth color transitions between zones. |
| **Icon, Compact number, Text size** | How the value is drawn. |

### Fill level

**Shows:** How full a tank or silo is, as a filling bar.

**Use it when:** The measure is a level and the useful reading is how full, not the number.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

| **Measure** | The measure that holds the level. |
| **Conditions** | Ranges with colors, for example green below 50 %, yellow below 80 %, red above. |
| **Display** | Vertical or horizontal bar. |

### Compare

**Shows:** Two values side by side, with the difference.

**Use it when:** You compare a value with an earlier one, or you need one KPI such as an average, total or peak over a period.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

| **Measure** | One measure with its aggregation, icon and icon color. |
| **Time range** | The period the value covers. |
| **Compact number** | Shorten large values, for example 1.2 k. |
| **Alignment, Text size** | How the value is drawn. |

## State

Is it running, open, on?

### Stat

**Shows:** The current value of one or more measures, colored by range, optionally with a sparkline.

**Use it when:** You want a big, glanceable number that changes color when it leaves its normal range.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

  alt="The Stat widget on a dashboard"

| Setting | What it does |
| --- | --- |
| **Measures** | One or more measures. Each row has a thing, a measure, an icon and an icon color. |

## Charts

How did it change?

### Chart

**Shows:** Measures over time. Pick a layout: **Line**, **Area**, **Bar**, **Scatter** or **Combination** (bars and lines on one chart). You can change the layout later in the widget's settings.

**Use it when:** You look at trends, compare measures, or check a value against a limit.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

<Screenshot
  page="visualize/widgets"
  id="10-chart"
  route="/dashboards/:id"
  state="Line chart with two temperature measures over the last 24 hours and one threshold line"
  alt="The Chart widget on a dashboard"
/>

| Setting | What it does |
| --- | --- |
| **Measures** | One or more rows. Each has a thing, aggregation, chart type, line style, stacking, Y-axis group, color and alias. |
| **Time range** | The period and the bucket size. Follows the dashboard unless you override it. |
| **Thresholds** | Horizontal lines with color and label. |
| **Display** | Chart or table. |
| **Show chart markers**, **Zoom allowed**, **Compact Y-axis labels** | Show points, allow zoom and pan, shorten large axis values. |
| **Legend placement** | Bottom, right or hidden. |
| **Y-Axis min value**, **Y-Axis max value** | The range of the Y axis. |

Older dashboards may contain separate line, bar, scatter and combination widgets. They keep working; new ones are layouts of this widget.

### Timeline

**Shows:** States over time as colored segments, one lane per measure.

**Use it when:** You want to see when something was running, idle or in error, not how large a value was.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

<Screenshot

| --- | --- |
| **Aggregation** | How values are combined. |
| **Merge consecutive datapoints** | Join neighbouring segments with the same state. |
| **Time range** | The period to show. |
| **Rules** | Map value ranges to colors and labels. |

### Heatmap

**Shows:** A measure by hour and day as a color grid.

**Use it when:** You look for daily or weekly patterns, such as when consumption peaks.

**Offered on:** Reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own.

| **Step** | Group by hour, day, week or month. |
| **Min / Max** | Optional range to clip values. |

**Shows:** Shares of a whole, as a doughnut or pie.

**Use it when:** You show how several measures contribute to a total.

**Shows:** Values by period in a table you can group by rows and columns.

**Use it when:** You need numbers rather than a picture, grouped and summed the way a report would.

What is it doing, and what can I do?

**Shows:** Maps a measure's value to an icon, text and color, for example online or offline.

**Use it when:** You want a plain-language state, such as Running or Fault, instead of a raw value.

## Events and rules

What happened, and what fired?

### Events

**Shows:** The events of the dashboard: on a tenant-wide dashboard every event of the tenant, otherwise the events of its things. One row per event, newest first.

**Use it when:** You want the recent history of what fired, with severity and type.

**Offered on:** Any dashboard. The picker lists it under **Thing details** on a dashboard about a thing.

<Screenshot
  page="visualize/widgets"
  id="19-events"

  state="Events list with severity chips and five rows"

/>

| Setting | What it does |
| --- | --- |
| **Event types** | One or more types to show. Empty means all. |
| **Time range** | Follows the dashboard unless you override it. |

Chips filter by severity and show counts. **Open event explorer** opens the events page with the same filter.

### Incidents

**Shows:** The problems someone is working on, newest activity first, with severity, number, who opened them and status.

**Use it when:** You want people to see what needs attention now.

**Offered on:** Any dashboard except reports. The picker lists it under **Thing details** on a dashboard about a thing.

<Screenshot

| **Opens on** | Start on active incidents or on all of them. |
| **Rows** | 5, 10 or 20 before **All incidents**. |
| **Card** | Background and border colors. |

Only members who may read incidents see it.

**Use it when:** You report on how many events there are, which thing types raise them, how often rules fire, or how often things cross geofences.

**Offered on:** General, Home and other Smart dashboards. Not on a dashboard about one thing.

## Overview

How is the tenant doing?

### Counter strip

**Shows:** Up to six tenant figures in one bar: things, things online, messages today, events and what the tenant stores. Each counter opens the list it counts.

**Use it when:** You build a Home dashboard and want the tenant's vital numbers on top.

**Offered on:** General, Home and other Smart dashboards. Not on a dashboard about one thing.

<Screenshot
  page="visualize/widgets"
  id="22-counter-strip"

  state="Counter strip with four tenant figures"
  alt="The Counter strip widget on a dashboard"
/>

| Setting | What it does |
| --- | --- |
| **Counters** | Pick up to six and drag them into order. **Reset to default** brings back Things, Things online, Messages today and Events. |
| **Time range** | Events, messages and average message rate cover the dashboard's range, or one of the widget's own. |
| **Card** | Background and border colors. |

A problem shows in the line under the figure, for example *2 offline*. A dash with *No access* means your role may not read that figure.

### Counter

**Shows:** The count of one resource type.

**Use it when:** You want one number, such as how many rules or users the tenant has.

**Offered on:** Thing, Thing type, Smart, Multi-asset and Report dashboards. General dashboards use the counter strip; counters placed there earlier keep working. The picker lists it under **Tenant figures** on dashboards about a thing.

## Statistics

The statistics cards (event statistics, **Health score**, **Messages**, connectivity statistics and data and access statistics) are one widget type, **Statistic**, with a preset per card. They need no data setup: pick the card and it works. Message figures come from platform metrics, which arrive in batches and can be up to 5 minutes behind. A viewer whose role cannot query metrics sees a note instead of the figures.
