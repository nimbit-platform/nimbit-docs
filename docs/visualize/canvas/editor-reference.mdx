Every tool, element and option of the canvas editor, as named in the app. For tasks, start at [Canvas](./index.mdx).

## Create a canvas

| Field | Values | Meaning |
| --- | --- | --- |
| **Name** | Text | Required. |
| **Interfaces** | Interfaces | Viewers pick a context thing that implements them. Empty: every element binds to a fixed thing. |
| **Start from** | **Blank canvas**, **From image**, **From P&ID drawing**, **From a template** | **From P&ID drawing** matches the drawing's tags to things (beta). A template is added **managed by Nimbit** or as **a copy to change freely**. |

## Toolbar

| Tool | Key | Does |
| --- | --- | --- |
| **Select tool** | <kbd>V</kbd> | Select and move. |
| **Hand tool** | <kbd>H</kbd> | Pan. |
| **Pen** | <kbd>P</kbd> | Freehand stroke. |
| **Line** | <kbd>L</kbd> | Straight line. |
| **Arrow** | <kbd>Shift</kbd>+<kbd>L</kbd> | Line with a head. |
| **Rectangle** | <kbd>R</kbd> | Rectangle. |
| **Ellipse** | <kbd>O</kbd> | Ellipse. |
| **Zone** | <kbd>Z</kbd> | Polygon area. |
| **Hotspot by hand** | none | Draw a clickable area. |
| **Pipe** | <kbd>C</kbd> | Connect equipment. |
| **Snap**, **Grid** | none | Line elements up. |
| Text, note | <kbd>T</kbd>, <kbd>N</kbd> | Add a **Text** or a **Note**. |
| Zoom in, out | <kbd>+</kbd>, <kbd>-</kbd> | Zoom. **Reset zoom** and **Center on content** are in the zoom menu. |

<kbd>A</kbd> opens the element search. <kbd>Ctrl</kbd>+<kbd>Z</kbd> undoes. Keys are ignored while you type in a field. In the editor, <kbd>Space</kbd> + drag pans, Shift-click adds to the selection, and dragging on the background selects several.

## Elements

| Section | Elements |
| --- | --- |
| **Data** | **Value**, **KPI**, **Gauge**, **Linear gauge**, **Fill level**, **Chart**, **Compact chart**, **Sparkline**, **State badge**, **State icon**, **State timeline**, **Thing card**, **Aggregate** |
| **Controls** | **Button**, **Switch**, **Setpoint**, **Hotspot** |
| **Draw & basic** | **Text**, **Note**, **Shape**, **Line**, **Zone**, **Image** |
| **Embeds** | **Dashboard widget**, **Canvas**, **Web page**, **VNC console** |
| **P&ID symbols** | **Tank**, pumps, valves and other process symbols |

Value, chart and thing card elements have a **Display** setting: **Canvas default**, **Full**, **Compact**, **Auto** or **Value tile, chart on hover**. Compact switches to a value chip below 96 × 72 px on screen.

## Inspector

Select an element to see its tabs. Nothing selected: *Select an element to edit its data, appearance, states and action.*

| Tab | Sets |
| --- | --- |
| **Data** | Where the value comes from. |
| **Appearance** | Look, position and size, **Align** and **Distribute**. |
| **States** | Rules that change the look with the value. |
| **Action** | What a click does. Only on buttons, symbols, hotspots, switches and setpoints. |

### Data options

| Option | Values | Meaning |
| --- | --- | --- |
| **Source** | **From context**, **Fixed thing** | The viewer's thing, or one device. |
| **Bind value** | Thing, measure or property | Searchable. For text, also date and time values: **Date & time**, **Date**, **Time**, **Day of week**, **Month**, **Year**. |
| **Thresholds** | **Equals**, **Greater than**, **Greater or equal**, **Less than**, **Less or equal**, **Range** | With a value, or **Min value** and **Max value**, a **Background** and a **Text color**. |
| **Consider data stale after** | Duration | Per element. Default is the canvas's. |

### State options

| Option | Values |
| --- | --- |
| **State from** | The bound value, shown live. |
| **When** | Operator and value. **Else if** adds a rule, **Otherwise** is the fallback. |
| **State** | A name, such as `running` or `high alarm`. |
| **Severity** | **Automatic**, **Normal**, **Info**, **Warning**, **Alarm**, **Fault**. Shown as **Stale** or **Unknown** when there is no current value. |
| **Color** | Any colour. Without one, warning, alarm and fault use their severity colour. |
| **Icon**, **Motion** | For icon elements. Motion: **Blink**, **Clock**, **Spin**, **No motion**. |
| **Applies to** | Text elements: **Whole text** or **Only this value**. |

**State timeline** states use **Equals**, **Below**, **Between** or **From**.

### Action types

| Type | What happens |
| --- | --- |
| **Run an action** | Runs one of the thing's actions on the **Target** thing. |
| **Navigation** | Opens another canvas or a link. |
| **Switch context thing** | Changes the thing the canvas shows. |
| **Set a variable** | Sets a canvas variable. Reports *Setting variables is not supported yet* where unsupported. |
| **None** | Nothing. |

Safeguards for **Run an action**: **Confirmation**, **Critical equipment** (typed confirmation), **Enabled only when**, **Expected result** with **Within**, **Cooldown**, **Consequence**, **Value sent**, **Label** and **More actions** (shown next to the main action).

## Pipes

A pipe or **Signal line** connects two elements. Select it to set **Label**, **Line type**, **Routing** and its **Data** values. A label can show a live value with `{{value1}}`, where `value1` is a value from the **Data** tab. Drag a bend to move it, double-click the line to add one, double-click a bend or press <kbd>Delete</kbd> to remove it. A new pipe's **Flow direction not confirmed** until you **Confirm** or **Flip** it; until then it stays out of the plant graph.

## Layers and arranging

| Where | Offers |
| --- | --- |
| **Layers** | Every element in drawing order. Rename, **Hide**, **Lock**. Elements on an image nest under it. **Pipes** are listed separately. |
| Selection bar | Align, distribute, group, duplicate, lock. |
| Right-click | **Bring to front**, **Bring forward**, **Send backward**, **Send to back**, **Copy**, **Paste**, **Duplicate**, **Group**, **Lock** or **Unlock**, **Delete**. |

## Canvas settings

| Setting | Meaning |
| --- | --- |
| **Name**, **Description** | Identify the canvas. |
| **Kind** | Sorts the canvas into the list's filters. |
| **Interfaces** | The interfaces viewers pick a context thing from. |
| **Theme** | The canvas's theme. |
| **Default time range** | The range a viewer starts on. |
| **Allow operation** | Lets buttons, switches, setpoints and valve actions send commands. Action permissions still apply. |
| **Compact when zoomed out** | Sets how elements on **Canvas default** shrink. |
| **Consider data stale after** | Canvas-wide default. |
| **Plant graph** | When enabled for the tenant, saved pipes can update the plant graph. |

## Save, preview and managed canvases

| Item | Meaning |
| --- | --- |
| **Preview** | Shows the canvas as viewers see it, in both themes. Commands are dry runs. **End preview** returns to editing. |
| Status | **Unsaved**, **Saving…**, **Saved**, **Conflict**. |
| **Save**, **Save and exit**, **Save as copy** | Publish, publish and leave, or keep your work as a new canvas after a conflict. |
| **Managed by Nimbit** | **Update to version …** applies a new template version. **Reset to Nimbit version** drops your changes. **Duplicate** gives a copy Nimbit no longer updates. |

## Viewer

| Item | Meaning |
| --- | --- |
| Thing picker | Chooses the context thing. The link you share keeps the choice. |
| Time range | A past range shows history; **Live** returns to now. |
| Alarm chip | Lists alarms and stale values. Select it for the next one. |
| Zoom | Drag to pan, scroll or Ctrl+scroll to zoom. |
