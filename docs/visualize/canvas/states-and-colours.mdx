Set rules on a bound element so that trouble stands out: a tank turns red, a pump icon spins, an alarm blinks. Rules decide a named state; the state decides how the element looks.

## Before you start
- A role that may update canvases.
- An element already bound to a value. Without a binding the **States** tab says to add a live value first. See [Bind elements to live values](./bind-live-values.mdx).

## Steps

1. Open the canvas, select **Edit canvas** and select the element.
2. Open the **States** tab. **State from** shows the value now.
3. Add a rule. Under **When**, pick the operator and the value, for example greater than a limit.
4. In **State**, name the state, for example `high alarm`.
5. Pick a **Severity**: **Automatic**, **Normal**, **Info**, **Warning**, **Alarm** or **Fault**. **Automatic** derives it from the state name (fault, alarm, warning); any other name is Normal.
6. Optional: pick a **Color**. Without one, a warning, alarm or fault takes its severity's colour, and quiet states keep the element's look. For icon elements you can also pick an **Icon** and a **Motion**: **Blink**, **Clock**, **Spin** or **No motion**.
7. Add more rules with **Else if**, and a fallback with **Otherwise**. Rules run top to bottom and the first match sets the state. Use **Move up** and **Move down** to order them.
8. For a text element, choose **Applies to**: **Whole text** or **Only this value**.
9. Select **Preview**, then **Save**.

For a **State timeline** element the rules are **States** instead: each has an operator (**Equals**, **Below**, **Between** or **From**) and a colour. Values that match no state are left blank. With no states defined, every distinct value gets its own colour.

## Check that it worked

In **Preview**, the element shows the colour, icon and motion of the matching state. When a value is in alarm, a chip in the canvas header lists it; selecting the chip jumps to the next alarm.

## If it doesn't work

- **The element keeps its normal look**: the matching rule has severity Normal and no colour. Pick a colour or raise the severity.
- **A rule never matches**: an earlier rule matches first. Reorder the rules.
- **The element turns Stale**: the value stopped updating. Set **Consider data stale after** on the **Data** tab.
- **Too many different values to color**: a timeline over a text measure has no states. Define states in the inspector.
