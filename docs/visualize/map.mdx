Open the map to see every thing that has reported a position, filter them, and replay where mobile things went. To draw areas that raise events, see [Draw a geofence](../watch/geofence.mdx).

## Before you start
- Things with a position. A thing that reports latitude and longitude in its data sets this by itself. For others, enter a location on the thing page with **Set location**. With none, the map says **No thing has a reported position yet.**
- To show a map on a dashboard instead, use the **Map** or **Thing List & Map** widget from the [widget gallery](./widgets.mdx).

## Find things

1. Open **Monitoring › Map**. The mode is **Explore**. The panel header reads **Things on map** with a count such as `12 of 15 with a position`.
2. Type a name or ID in the search box. It shows the first matches; refine the search to see more.
3. Narrow the map with filters. **Reset** clears them.
4. Select a pin for the thing's name, connection and last position. **Open thing** goes to its page.
5. Select **Fit to things** to zoom to what is shown.

| Filter | Options |
| --- | --- |
| **Thing type** | One or more thing types |
| **Things** | Single things |
| **Tags** | Things with these tags |
| **Connection** | **Online**, **Offline**, **Stale · no fix 30 min+** |
| **Last position** | **Any time**, **Within 15 min**, **Within 1 h**, **Within 24 h**, **Older than 24 h** |
| **Motion** | **Any**, **Moving**, **Parked** |
| **Geofence** | **Anywhere**, or **Inside** a chosen geofence |

Use **Color by** to color pins by **Status** or **Thing type**. Square or arrow pins are mobile things. Close pins group into clusters; zoom in to split them.

## Replay a route

1. Switch to **Routes**.
2. Select mobile things in the panel, up to 10.
3. Pick a **Time window**: **24 h**, **7 days** or **30 days**.
4. Select **Show routes**. The map draws each route and the panel shows the distance, for example `42 km total`.
5. Select **Play**. Change the **Playback speed**, and use **Point spacing** to thin a dense track.

**Stops & dwell** lists places where the thing stayed. **Minimum dwell** hides short stops, **Highlight travelled part** marks how far the replay has got, and **Fit to routes** zooms to the tracks.

The mode is in the address (`?mode=routes`), so you can bookmark it. **Geofences** and **Events** modes are covered in [Draw a geofence](../watch/geofence.mdx).

## Check that it worked

Pins appear for the filtered things and the count matches the panel. In **Routes**, the route and distance show for each selected thing.

## If it doesn't work

- **A thing is missing**: it has no position. Set one on its thing page, or send latitude and longitude.
- **Fewer things than expected**: a filter is active. Select **Reset**.
- **No route drawn**: the thing sent no positions in the time window. Pick a longer window.
