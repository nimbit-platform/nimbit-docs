Lookup tables for gateways. For the model, read [How gateways work](./how-gateways-work.mdx).

## Gateway types

| Type | Identity | Needs | Own thing type |
| --- | --- | --- | --- |
| **Periscope** | Key pair registered at enrollment | A one-time onboarding code | `periscope_gateway` |
| **MQTT device** | Broker username and password | A config file or the shown credential | `mqtt_gateway` |

Every gateway has one thing of its own, with the alternate ID `gateway-<id>`. It is created with the gateway and stays with it.

## Fields

| Field | Applies to | Rules |
| --- | --- | --- |
| **Name** | Both | 1 to 100 characters, unique in the organization. |
| **Namespace** | Both | 1 to 64 characters from `a-z`, `0-9`, `_` and `-`. Without one, it follows the name. Can't be `gateway`. It can't equal another gateway's namespace, start with it, or extend it with `-`. Fixed once the gateway has things or, for Periscope, its box has enrolled. Renaming doesn't move existing things. Things of a Periscope gateway must have an alternate ID that equals it or starts with `<namespace>-`. For an MQTT device gateway this is not checked. |
| **Roles** | Periscope | The roles the gateway acts with, narrowed to what a gateway may do. Default: **Modeler**. You can't give a role with permissions you lack. |
| **Code valid for** | Periscope | 1 hour to 7 days. Default 1 day. |
| **Config file format** | MQTT device | **Environment file (.env)**, **JSON (.json)** or **eWON Flexy BASIC parameters (.bas)**. |
| **Allowed thing types** | Scope | Up to 200. Empty means any thing type. |
| **Thing limit** | Scope | 0 to 100,000, besides the gateway's own thing. Empty means only the organization's limits apply. |
| **Creation policy** | Scope | **Open** creates things inside the scope. **Locked** creates none by any path: data for an unknown thing is discarded and counted, and existing things keep working. It doesn't apply when you assign things. MQTT device messages never create things. |

## Statuses

| Status | Meaning |
| --- | --- |
| **Online** | The gateway thing is connected: its own health message arrived in the last 15 minutes. |
| **Offline** | Enrolled, and the gateway thing is not connected or has no health message yet. |
| **Waiting for onboarding** | An onboarding code is pending. |
| **Not enrolled** | Periscope: no live key and no pending code. MQTT device: its credential is revoked. |
| **Incomplete, delete it** | Only the identity directory knows the gateway. Delete it and add it again. |

## Limits

| Limit | Value |
| --- | --- |
| Periscope gateways per organization | 1000 |
| Gateways a thing belongs to | 1 |
| Things assigned in one action | 200 |
| Alternate ID length | 128 characters |
| Sign-in token of a Periscope box | 5 minutes |
| Gateway token for HTTP and stream ingest | 10 minutes at most |
| MQTT session of a gateway | 10 minutes at most |
| Onboarding code validity | 1 hour to 7 days |
| Allowed thing types per gateway | 200 |
| MQTT batch | 1 MiB, and 500 elements by default |
| Events per page | up to 200 |

## MQTT connection

| Item | Value |
| --- | --- |
| Client ID | `<tenant>:gateway:<gateway id>`, optionally followed by `:<suffix>` |
| Protocol | MQTT 3.1.1 |
| QoS | 0 or 1 |
| Topics | **Telemetry topic** for one thing, **Batch topic** for an array, **Status topic** for health. All under the **Topic prefix** |

Batch element fields: `id` (required), `thingType`, `time`, `data`. Element and message rules are in [Message format](../connect/message-format.mdx), topics in [MQTT topics and client ID](../connect/mqtt-topics.mdx).

## Health measures

The gateway reports these about itself every 5 minutes (interface `GatewayHealth`). `data` must not be empty. Send them live; replaying a buffered message would keep a dead gateway online.

| Name | Meaning | Unit |
| --- | --- | --- |
| `uptime_s` | Uptime | s |
| `buffer_used_pct` | Buffer used | % |
| `buffer_oldest_s` | Oldest buffered message | s |
| `errors_per_min` | Errors per minute | 1/min |
| `clock_offset_ms` | Clock offset | ms |
| `sw_version` | Software version (property) | |
| `link_type` | Link type (property) | |

A Periscope gateway adds the interface `PeriscopeAgent`: `outputs_failing`, `inputs_failing`, `output_p95_ms`, `restart_required`, `config_hash` and `last_apply`.

## Traffic measures

The platform writes these to the gateway thing about every minute (interface `GatewayTraffic`). They never make a gateway online. With several ingest instances, each writes its own share, so a reading can be one instance's view.

| Measure | Meaning |
| --- | --- |
| `traffic_messages_per_min` | Messages stored per minute |
| `traffic_values_per_min` | Measure values stored per minute |
| `traffic_things_active` | Things with a stored message in the window |
| `traffic_last_data_age_s` | Seconds from the last stored message to the window's end |
| `discards_per_min` | Messages refused for good per minute, all reasons |
| `discards_<reason>_per_min` | The same per reason, 0 when none |

## Discard reasons

| Reason | Counted when |
| --- | --- |
| `identity_mismatch` | The message names another organization or thing than its connection |
| `not_member` | The thing's record names another gateway, or none |
| `unknown_thing` | The thing or its thing type doesn't exist |
| `invalid` | Anything else refused for good: undecodable, malformed, no `thingType`, no data or location, a batch that is not an array or object, the wrong thing type for the thing |
| `id_missing` | A batch element has no `id` |
| `too_large` | A batch is over 1 MiB, dropped whole, counted once |
| `too_many` | A batch has more elements than the limit (500 by default), dropped whole, counted once |

A lookup the platform couldn't answer is retried, not discarded. A batch element is checked on its own: a bad one is dropped and the rest are stored.

## Refused creates

A Periscope gateway's attempt to create a thing can be refused. **Refused creates** on the **Scope** tab counts them by reason, and the **Events** tab lists each one.

| Reason | Meaning |
| --- | --- |
| **Thing limit reached** | The gateway has as many things as its limit allows. |
| **Creation locked** | The creation policy is **Locked**. |
| **Outside the namespace** | The thing's alternate ID doesn't start with the gateway's namespace. |
| **Thing type not allowed** | The thing type isn't in the allowed list. |

## Assignment refusals

When you assign things, IoT Breeze names the reason for each thing it leaves as it was.

| Message | Meaning |
| --- | --- |
| **Thing limit reached** | The gateway has as many things as its limit allows. |
| **Thing type not allowed** | The thing type isn't in the allowed list. |
| **Outside the namespace** | A Periscope gateway's thing needs an alternate ID inside the namespace. |
| **A gateway's own thing stays with its gateway** | Gateway things can't be moved. |
| **Not found, or not yours to change** | The thing doesn't exist or you can't change it. |
| **Its provider keeps its alternate ID** | **Move alternate IDs into the namespace** needs a thing of the NimBit provider. |
| **The moved alternate ID is another thing's** | The new alternate ID is in use. |
| **No alternate ID inside the namespace can be made from it** | The moved ID would be empty or over 128 characters. |

## API error codes

These codes come back in the `code` field of an API error.

| Code | Status | Meaning |
| --- | --- | --- |
| `GATEWAY_NAME_TAKEN` | 409 | A gateway with this name exists. |
| `GATEWAY_LIMIT_REACHED` | 409 | The tenant has the most gateways it may have. |
| `GATEWAY_NAMESPACE_TAKEN` | 409 | The namespace equals, starts with or extends another gateway's, or is reserved. |
| `GATEWAY_NAMESPACE_LOCKED` | 409 | The namespace is in use: the gateway has things, or its Periscope box has enrolled. |
| `GATEWAY_TYPE_MISMATCH` | 409 | The call doesn't fit the gateway type: an MQTT device gets a new credential, a Periscope box a new code. |
| `GATEWAY_NOT_IN_DIRECTORY` | 409 | The identity directory doesn't know the gateway. |
| `GATEWAY_TOKEN_REQUIRED` | 403 | Only a gateway's own token may ask for the gateway credential or its `me` call. |
| `GATEWAY_SCOPE_REQUIRED` | 403 | A gateway's token may ask only for the gateway credential, not the tenant one. |
| `GATEWAY_SCOPE_NAMESPACE` | 403 | The alternate ID is outside the namespace. |
| `GATEWAY_SCOPE_THING_TYPE` | 403 | The thing type is not allowed. |
| `GATEWAY_LOCKED` | 403 | The creation policy is **Locked**. |
| `GATEWAY_SCOPE_LIMIT` | 409 | The thing limit is reached. |
| `GATEWAY_THING_PROTECTED` | 403 | A gateway's own thing can't be deleted, and a gateway can't change it. |
| `GATEWAY_DEVICE_CREDENTIAL_REFUSED` | 403 | A gateway's token may not create per-device credentials. |

## Events

The **Events** tab shows changes to the gateway and its gateway thing, the directory's record of its keys and a pending onboarding code (**Key registered**, **Key used**, **Onboarding code pending**), and refused creates. The identity directory keeps no history of its own.
