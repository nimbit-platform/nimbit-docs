# Anomaly Detection Models

This page covers the anomaly detection models available in the project. These models are specialized in identifying unusual patterns, making them ideal for spotting anomalies in time series data.

## K-Means Clustering

K-Means groups similar data points, which helps in identifying outliers or unusual patterns.

<Admonition type="info" title="Quick Insight">
  K-Means works well when you have large datasets and need to group similar data points!
</Admonition>

### Applications

- **Anomaly Detection**: Highlights data points that do not fit into any cluster, marking them as anomalies.

---

## Wasserstein Distance Model

The Wasserstein model is specifically designed to detect anomalies by comparing distribution patterns.

<Admonition type="tip" title="Did you know?">
  Wasserstein distances are used for anomaly detection by measuring differences between distributions.
</Admonition>

### Applications

- **Comparing Patterns**: Useful for identifying small but significant shifts in data.

---

## PyOD (Python Outlier Detection)

PyOD provides a suite of tools to detect outliers in data, making it easier to spot sudden changes.

<Admonition type="caution" title="Heads Up!">
  PyOD is versatile, offering multiple techniques for outlier detection!
</Admonition>

### Applications

- **Spike Detection**: Helps catch unusual spikes or drops.
- **Anomaly Flagging**: Flags data that deviates significantly from the norm.

---

By using these models, you can effectively detect anomalies and gain insights into unusual patterns within your data.
