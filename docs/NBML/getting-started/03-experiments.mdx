## What are Experiments?

In the context of machine learning, an **experiment** is a structured way to group different run. Each run (individual attempts or trials) use different datasets, models or hyperparameters helping you progressively improve training performance.

:::info
An experiment is a key component in improving your machine learning models. It allows you to track multiple configurations and performance metrics efficiently.
:::

In our system, an **experiment** is a workspace where you can:
- Test different model configurations.
- Track and log performance metrics.
- Compare the results of multiple runs.

:::tip
It's a good idea to **tag** your experiments with descriptive names and labels so you can easily filter and search through them later.
:::

By organizing your work into experiments, you can efficiently manage and compare different approaches, improving the chances of finding the best-performing models.

### What You Can Do with Experiments

Our system provides a range of features for managing machine learning experiments. Here’s what you can do:

- **View all experiments**: Get a complete list of all the experiments you’ve created. This helps you keep track of your ongoing work and gives you quick access to each experiment.
  
- **Retrieve a specific experiment**: Look up details about a specific experiment, including its parameters, configurations, and results. This is useful when you want to focus on a single experiment at a time and examine its performance.

- **Create a new experiment**: Start a new experiment where you can test new models or approaches. You can specify details like the experiment name, description, and other settings that will guide the system on how to run the experiment.

- **Update an existing experiment**: If the parameters or goals of an experiment change, you can update it. This allows you to modify the experiment without having to recreate it from scratch.

- **Delete an experiment**: If an experiment is no longer needed or was created by mistake, you can permanently delete it from the system. This helps keep your workspace organized and free of unnecessary clutter.

:::danger
Once you delete an experiment, **it cannot be recovered**. Make sure you back up any important data before proceeding.
:::

### How These Endpoints Work

Each of these operations is supported through specific actions, called **endpoints**, that are built into the system. These endpoints allow you to interact with your experiments, whether you are creating new ones, updating existing ones, or retrieving results.

By using these endpoints, you can:
- Efficiently manage multiple machine learning experiments.
- Track results and compare performance metrics across different experiments.
- Adjust experiments as needed to fine-tune your models.

This streamlined approach helps you get the most out of your machine learning projects by allowing you to focus on model improvement, experimentation, and comparison of results.
