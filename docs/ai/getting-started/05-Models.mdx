## What are Models?

In machine learning, a **model** is an algorithm trained on data to make predictions or decisions. Once a model is trained, it can be used to forecast future trends, identify patterns, or automate decision-making. Models are created by training them with data and the system stores these models for further use.

Models play a central role in the system as they represent the "trained" state of your algorithms. Whether for forecasting, anomaly detection, or other tasks, models are used to apply machine learning to real-world problems.

### What You Can Do with Models

The system offers several ways to interact with and manage models. Here's an overview of what you can do:

- **View all models**: You can look through a list of all the machine learning models stored in the system. This is helpful when you have multiple models and you want to keep track of them.

- **Look up a specific model**: You can find detailed information about a particular model, such as its name, type and configuration. This is useful when you need to review a specific model and its settings.

- **Add a new model**: You can create and store new models in the system. When a new model is trained, it can be added with all its details, such as its type, configuration and parameters.

- **Update an existing model**: If a model needs adjustments or improvements, you can modify it. This allows you to change the model's configuration or metadata without creating a new model.

- **Remove a model**: When a model is no longer needed, you can delete it from the system. This helps you keep your workspace tidy by removing outdated or unnecessary models.

- **Download a trained model**: Once a model is trained, you can download it for use elsewhere. This is helpful if you want to deploy the model outside the system or run additional tests.

### Features for Managing Models

Here’s what you can do with the models in more detail:

#### View Models

You can easily view all the models available in the system. This gives you a complete overview of all the models, including basic information like their name, type and any specific configurations.

#### Retrieve Specific Models

You can look up a specific model to get a deeper understanding of its details, such as the parameters used during its creation and its purpose. This helps you find the right model when working on a particular problem or experiment.

#### Add New Models

When a new machine learning model is created, you can store it in the system by adding its details. You can include information like the model type, configuration and any additional settings, so the model is ready for future use.

#### Update Existing Models

If a model needs to be changed (for example, if you want to update its hyperparameters or adjust how it behaves), you can update it instead of creating a new one. This ensures that your models remain current and perform as expected.

#### Delete Models

You can remove models that are no longer in use or that have been replaced by newer versions. Deleting models ensures that your system remains organized and that only relevant models are available for use.

:::danger
Be cautious when deleting models, as this action cannot be undone. Once a model is deleted, it is permanently removed from the system.
:::

#### Download Models

Once a model has been trained and stored in the system, you can download it for use in other environments. This is especially helpful if you want to deploy the model elsewhere or perform additional testing outside the system.

:::tip
Make sure to download the correct version of the model for the right experiment and run to avoid confusion.
:::

---

These features make it easy to manage machine learning models, whether you are adding new ones, modifying existing models, or retrieving stored models for further use.
