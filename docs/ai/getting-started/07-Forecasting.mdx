## What is Time Series Forecasting?

**Time series forecasting** is the process of analyzing historical data to predict future trends or outcomes over time. It’s used in various fields such as finance, weather prediction and sales forecasting. By looking at past patterns and trends, forecasting models help predict what might happen in the future.

In our system, time series forecasting can be automated using various models, or you can bring your own model to generate predictions. The system provides several ways to interact with forecasting models, allowing users to analyze data, train models and generate forecasts.

### What You Can Do with Time Series Forecasting

Our system offers a range of features to help you manage and perform time series forecasting:

- **Get model suggestions**: Based on the metadata of your dataset, the system can suggest appropriate forecasting models.
- **Train a forecasting model**: You can train a model using your data and get predictions by specifying how to split your data for training and testing.

- **Live forecasting**: This feature allows you to make real-time predictions using the most recent data available.

- **Use your own model**: You can upload a pre-trained model (in `pkl` format) to make predictions using your own custom algorithms.

### Forecasting Features in the System

Here’s a breakdown of the main actions you can take when working with forecasting models:

#### Model Suggestions

The system can analyze the metadata of your dataset and suggest suitable forecasting models. This is helpful if you’re unsure about which model to use.

#### Train a Forecasting Model

You can train a new forecasting model using your dataset. This involves splitting the data into training and testing sets, which allows the model to learn from the historical data and then make predictions on future data.

#### Live Forecasting

Live forecasting enables you to use the most recent data for real-time predictions. This is particularly useful when you need up-to-date insights to make immediate decisions.

#### Bring Your Own Model

If you already have a trained forecasting model, you can upload it in `pkl` format and use it for making predictions on your dataset. This is a flexible option if you have custom algorithms that are better suited for your specific data.

:::tip
When using your own model, make sure that the model has a `predict` method that the system can call to generate forecasts.
:::

### Forecasting Management Features

#### Get Model Suggestions

The system can provide model suggestions based on your dataset’s metadata. This is useful when you want to know which forecasting models might work best for your specific data.

#### Train a Model and Make Predictions

You can train a forecasting model using a dataset and make predictions on test data. This helps you test how well the model performs before using it in real scenarios.

#### Perform Live Forecasting

This feature allows you to continuously generate predictions using the latest data. Live forecasting is particularly useful when the data is updated in real-time and immediate insights are needed.

#### Forecast with Your Own Model

You can bring your own model, upload it in the system and make predictions using your custom algorithm. This gives you the flexibility to apply your own models, especially if you have specific needs or have developed models outside the system.
