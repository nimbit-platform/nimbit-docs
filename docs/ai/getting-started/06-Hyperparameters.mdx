## What are Hyperparameters?

In machine learning, **hyperparameters** are adjustable values that influence how a model is trained. Unlike the model’s internal parameters, which are learned from the data during training, hyperparameters are set before the training process begins and play a crucial role in optimizing the model's performance.

Examples of hyperparameters include learning rate, batch size, number of layers and epochs. By fine-tuning these values, you can improve the accuracy, speed and generalization ability of your models.

### What You Can Do with Hyperparameters

The system provides several ways to manage hyperparameters for machine learning models. Here's what you can do:

- **View all hyperparameters for a model**: You can look up all the hyperparameters associated with a specific model. This gives you a comprehensive view of how the model was configured for training.

- **Find a specific hyperparameter by ID**: You can retrieve a single hyperparameter for a model by its unique ID, allowing you to focus on specific aspects of the model's configuration.

- **Add new hyperparameters for a model**: If you are configuring a model for training, you can add new hyperparameters that define how the training should be performed.

- **Update existing hyperparameters**: If you need to adjust the hyperparameters of a model, you can update them to improve the model’s performance or test different configurations.

- **Delete hyperparameters**: If certain hyperparameters are no longer needed or relevant, you can remove them from the system.

:::tip
When tuning hyperparameters, it’s important to experiment with different values to find the optimal configuration that works best for your model and dataset.
:::

### Hyperparameters Management Features

Here’s a breakdown of the different actions you can take with hyperparameters in the system:

#### View All Hyperparameters for a Model

You can easily retrieve all the hyperparameters associated with a specific model. This is useful for reviewing the configuration of a model, especially when you have multiple models with different hyperparameter settings.

#### Find a Specific Hyperparameter by ID

You can find and view a single hyperparameter using its unique ID. This helps you narrow down and focus on particular hyperparameters that may need further analysis or adjustment.

#### Add New Hyperparameters for a Model

When setting up a new model or reconfiguring an existing one, you can add new hyperparameters to control how the training is performed. This allows you to customize the training process for each model.

#### Update Existing Hyperparameters

If you want to improve model performance, you can update the hyperparameters and try new configurations. This is a key part of the model optimization process, allowing you to test different settings and see how they affect the model's performance.

#### Delete Hyperparameters

You can remove hyperparameters that are no longer needed for a model. Deleting outdated or irrelevant hyperparameters helps keep the model configuration clean and organized.

:::danger
Be cautious when deleting hyperparameters, as this action cannot be undone and you may lose valuable configuration data.
:::

By managing hyperparameters effectively, you can improve your machine learning models' accuracy, efficiency and overall performance. These features allow you to adjust and fine-tune your models to achieve better results.
