# AI Intro

Welcome to the documentation of **NBML**.

## Overview

This application leverages advanced machine learning and deep learning techniques to provide solutions in time series forecasting. It offers APIs, focusing on automation, scalability and user-friendliness for both experts like data scientists and engineers and user with no prior knowledge to ml that want to explore Timeseries Forecasting and Anomaly Detection.

### Key Features

- **Forecasting APIs:** Support for custom time series datasets and integration with popular data analysis tools.
- **Codeless Interaction:** Minimal coding required to set up and deploy models.
- **MLOps Integration:** Seamless integration with MLOps tools for experiment tracking, deployment and monitoring.
- **Security and Access Control:** Built-in identity management for secure access to resources.
