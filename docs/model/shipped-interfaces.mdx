IoT Breeze ships one interface. It appears under **Devices › Interfaces** on the **Preshipped** tab, and is read-only: you can attach it, compare its versions and update to a newer one, but you can't edit it.

## Temperature Sensing

Ambient temperature and humidity. Its maturity is **Stable**.

| Property | Value |
| --- | --- |
| Display name | **Temperature Sensing** |
| Name | `temperature-sensing` |
| Current version | v1 |
| Maturity | **Stable** |

| Field | Kind | Type | Unit | Display name | Aliases |
| --- | --- | --- | --- | --- | --- |
| `temperature` | Measure | `numeric` | `°C` | Temperature | `temp` |
| `humidity` | Measure | `numeric` | `%` | Humidity | `rh`, `relativeHumidity` |

Both fields are flagged **Timeseries relevant**.

### Starter content

The **Temperature sensing** pack adds content built on this interface. A tenant admin installs it under **Devices › Packs**; see [Packs](../administer/tenant-settings.mdx#packs).

| Item | What it is |
| --- | --- |
| **Temperature Sensing** dashboard | A Smart dashboard with two gauges: temperature from -20 to 60, humidity from 0 to 100. |
| **Room overview** canvas | Tiles with comfort bands, gauges and a 24-hour chart for one room. Works for any thing whose type implements the interface. |
