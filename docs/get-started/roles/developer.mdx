You send data from your own code or gateway and integrate IoT Breeze with other systems. Read these pages in this order.

## Read in this order

1. [Connect a real device](../real-hardware.mdx): a first message over MQTT, end to end.
2. [Gateways and edge](../gateways/index.mdx): Periscope discovers OPC UA, Sparkplug, Modbus and MQTT sources and streams them in.
3. [Send data over MQTT](../connect/mqtt.mdx): connect, publish and receive commands.
4. [Message format](../connect/message-format.mdx): every field of a message.
5. [Ingest endpoints and status codes](../connect/ingest-endpoints.mdx): the HTTP endpoints and what each answer means.
6. [API overview](../api/index.mdx): the three APIs and when to use which.
7. [Authentication](../api/authentication.mdx): tokens, keys and where to send them.
8. [Errors and limits](../api/errors-and-limits.mdx): what failures look like and how to retry.
