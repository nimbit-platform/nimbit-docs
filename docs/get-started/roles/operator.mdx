You watch things and react when something needs attention. Read these pages in this order.

## Read in this order

2. [Work an incident](../watch/work-an-incident.mdx): acknowledge, assign and resolve a problem.
3. [Check a thing's health](../watch/thing-health.mdx): is it connected, and what did it last report?
4. [Dashboards, smart dashboards and time](../visualize/dashboards.mdx): read a dashboard and look back in time.
5. [Explore telemetry over time](../watch/explore-telemetry.mdx): chart and compare raw measurements.
6. [Show things on a map](../visualize/map.mdx): see where things are and what state they are in.
7. [Ask a question about your data](../knowledge/ask.mdx): get an answer in plain words.
8. [A device shows no signal](../troubleshooting/no-signal.mdx): the first checks when data stops.
