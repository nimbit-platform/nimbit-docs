You decide who can do what in the tenant, and you keep it set up. Read these pages in this order.

3. [Invite a colleague](../administer/invite.mdx): add a user with a role.
4. [Give a team access to its things](../administer/team-access.mdx): build the group tree.
5. [Tenant settings](../administer/tenant-settings.mdx): name, features and email.
6. [Brand your tenant](../administer/branding.mdx): logos and theme.
