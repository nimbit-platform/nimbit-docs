IoT Breeze has guided tours: short walkthroughs that point at each part of a screen and wait while you try it. A guide is a series of tours that build on each other. Select a tour below to open it in your IoT Breeze; it starts once the screen has loaded.

The links open the address set next to **Open IoT Breeze** at the top of this page. If your IoT Breeze runs on your own domain, set it there first.

You can also start tours inside IoT Breeze from the help menu, where each tour shows whether you have finished it.
