Someone already set up your tenant and you want to know where things are. This tour takes about 10 minutes. The same tour runs in the app: open the **?** help drawer and choose **Find your way**.

Home shows the dashboard your admin assigned to it: usually things online, messages and alerts at a glance.

## Monitoring

Everything you watch day to day.

| Page | What you do there |
| --- | --- |
| Dashboards | Open, build and share dashboards. |
| Things | Find a device, see its live values, history and connections. |
| Map | See where your things are and what state they are in. |
| Incidents | Work through problems that need someone to act. |
| Events | See what happened, when, and on which thing. |
| Telemetry | Query and compare raw measurements. |
| Canvas | Floor plans and diagrams with live values. |

## Knowledge: Explore and Ask Nimble

If your tenant uses Contexus, **Knowledge › Explore** shows how sites, buildings, rooms and things relate. **Ask Nimble** (Ctrl/⌘+I) answers questions about your data in plain words, for example *"Which rooms were warmer than 24 °C yesterday?"*

## Settings and Administration

You may not see all of these; it depends on your role.

- **Onboarding:** things, thing types and interfaces.
- **Knowledge setup:** data model, sources, data health, AI models.
- **Automation:** Rule Designer, reports, Node-RED.
- **Configuration:** event types, incidents, notification channels, mail templates, geofences.
- **Administration:** files, users, groups, roles, gateways, API keys, audit log, tenant settings.

## Help when you need it

- **?** in the header opens help for the page you are on, with links to these docs.
- **Search** (Ctrl/⌘+K) finds pages, things and dashboards.
- Guided tours start from the help drawer.
