Released 1 April 2026. This release redesigns the thing type and user pages and moves report schedules into the report form. It also fixes many forms and tables.

## Improved

**Things**
- The thing type page has a new design.

**Users and groups**
- The user page has a new design.

**Reports**
- The report schedule is now part of the report form.

**Email**
- Email sending through Microsoft OAuth now works through the common Graph endpoint.

**Dashboards**
- Dashboards, reports, monitoring and automation pages received a round of updates.

## Fixed

- Reports are now generated with the correct date and time.
- Reports: the time range is validated correctly.
- Groups: inherited permissions are no longer shown in the wrong colour.
- Widgets: merged rows in the pivot table now display correctly.
- Thing types: fixed a problem in the measure form.
- Hierarchy: renaming an entry in the hierarchy form now saves the new name.
- Canvas: the name column now displays correctly.
- Tables: the select column and its checkbox are now aligned.
- Forms: the filter keyboard shortcut no longer fires while a form is open.
