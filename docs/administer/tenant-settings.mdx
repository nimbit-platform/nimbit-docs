The tabs of **Administration › Tenant Settings**, which apply to everyone in the tenant. Only the **Admin** role can open it (it needs permission to update the tenant).

Changes on **General**, **Features**, **Theme** and **Email** are saved together with **Save**. A badge shows **Unsaved changes**. **Reset to default** resets theme colors, branding images and email settings after confirmation and cannot be undone.

## General

| Setting | Meaning |
| --- | --- |
| **Name**, **Tenant Id** | Read only. |
| **Display name** | The name people see in the app. |
| **Time zone**, **Language** | Defaults for the tenant. |
| **Allowed hosts** | Sites that may be embedded, for example on canvases. One host per line, such as `grafana.example.com`, or `*.example.com` for all subdomains. Empty allows none. |
| **Branding Images** | **Favicon** (`.ico`, 48 × 48), **Default logo**, **Light mode logo**, **Dark mode logo** (PNG or SVG, up to 5 MB) and **Cover image** (PNG, SVG, JPEG or WebP, up to 5 MB). See [Brand your tenant](./branding.mdx). |

## Features

| Feature | Effect |
| --- | --- |
| **Dashboard hierarchy** | Groups dashboards in a tree of sites, buildings or areas, with a **Table** / **Hierarchy** switch on Dashboards. Turning it off hides the tree. Nodes and filed dashboards return when you turn it on again. |
| **Dashboards open in** | **Table** or **Hierarchy**. Applies to people who have not used Dashboards yet. After that it opens where each person left it. |
| **Ask Nimble and Knowledge** | The AI assistant and the Knowledge section. May be unavailable on your installation. A feature can show **On until** a date. |

## Theme

| Setting | Meaning |
| --- | --- |
| **Tenant default appearance** | **Light** or **Dark**, for people without a personal preference. They can override it with the theme control in the header. |
| Theme editor | Colors, layout and shadows per color mode. Select a preview to edit that mode. |

## Email

| Provider | Meaning |
| --- | --- |
| **System default** | Mail goes out from the platform mail server. No setup. |
| **Microsoft 365** | Sign in with Microsoft (OAuth2). **Save** first, then **Sign in with Microsoft**. Optional **Shared mailbox address** to send from it. **Sign out** before switching provider. |
| **Custom SMTP** | Your own mail server. Turn on **Enable custom SMTP**. |

Custom SMTP fields: **Host**, **Port** (587 by default), **Username**, **Password**, **From**, and the security **STARTTLS** or **SSL/TLS**. **Send a test mail** sends a mail with the current configuration and needs an enabled provider.

## Statistics

Read only.

| Item | Shows |
| --- | --- |
| **Row Count**, **Storage** | Measurements and the space they use, each with the value for **Yesterday**. |
| **Total file size in storage** | Size of all files in the tenant. |
| Area charts, **Last 30 Days** table | Row count and storage per day. **No data available** before any measurement arrives. |

## Schedules

Read only list of the tenant's task schedules.

| Column | Meaning |
| --- | --- |
| **URI**, **Owner** | What runs and who owns it. |
| **Timing** | For example `every 15m`, `cron: 0 6 * * *` or `once @ date`. |
| **Invocation**, **Status**, **Enabled** | How it runs, its state and whether it is on. |
| **Last run**, **Next run** | Run times. |

Data deletions appear here while they are scheduled or running. See [Delete data](./delete-data.mdx).

## Data

Shows the data stores to everyone who may read them. **Delete recorded data** needs the **Data deletion** permission. See [Delete data](./delete-data.mdx).

## Packs

Packs are starter content from Nimbit: mail templates and blocks, interfaces, dashboards and canvases. Installed items belong to your tenant and you can edit them.

| State | Meaning |
| --- | --- |
| **Not installed** | Not in your tenant. |
| **Current** | Installed and equal to the shipped version. |
| **Update available** | Nimbit ships a newer version. |
| **Edited** | You changed it. |
| **Deleted** | You deleted it. |

| Button | Effect |
| --- | --- |
| **Install**, **Install missing items** | Adds the pack's content. |
| **Reset** | Replaces an item with the shipped version, or recreates it if deleted. Your changes are lost. |
| **Uninstall** | Content stays as your own but gets no updates. Installing again creates new copies. A pack that others require, or whose content is in use, cannot be uninstalled. |

Filter by **Content type** at the top.

## Connections

Provisioning and messaging providers of the tenant.

| Item | Meaning |
| --- | --- |
| **Managed by Nimbit** | Internal providers. You can turn them on or off, not delete them. Turning one off asks **Deactivate**: things using it lose their connections and cannot send messages. |
| **Tenant connection** | The address a thing connects to. Replace `<deviceId>` with the thing's ID. |
| Credentials | Not stored. Generated tokens are available only in the current browser session. |
