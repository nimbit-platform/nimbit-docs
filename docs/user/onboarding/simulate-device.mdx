You can test dashboards, rules and charts before the real device is online. IoT Breeze can send data for a thing in two ways:

| Way | Use it for |
| --- | --- |
| **Send once** | One message, for example to check that a measure arrives, or to trigger a rule with a specific value. |
| **Simulate** | A stream of messages for up to four hours, to fill charts and test dashboards. |

You need the permission to send data to devices. Without it, the buttons are not shown.

## Open the dialog

1. Open the thing (**Settings › Onboarding › Things**).
2. Select **More actions** in the header, then **Send data** (opens **Send once**) or **Simulate device…** (opens **Simulate**).

If the thing has never reported, **Overview** offers **Send a test message** directly.

The **Send data** dialog has the two tabs **Send once** and **Simulate**.

## Send once

1. In the **Fields** view, each measure of the thing type is a row with **Measure** and **Value**. The values start from the last reading, or from a default for the type.
2. Untick the measures you do not want to send. **Include all measures** switches all rows at once.
3. Under **Timestamp**, choose **Now** or **Pick a time…**.
4. Select **Send message**.

The footer says how many measures are sent. The values show up in **Live values** within a second.

To also send location or tags, edit the message as JSON. The JSON is the same message as the fields: delete a measure to leave it out, and add `geo` and `tags` there.

## Simulate

1. Choose **Run for**: 15 minutes, 30 minutes, 1 hour or 4 hours.
2. Choose **Every**: how often a message is sent. The choices run from 1 second to 5 minutes. The default is 10 seconds.
3. For each measure, choose a **Shape** and the **Min** and **Max** of the values. **Preview** draws what it will look like.
4. Select **Start simulation**.

The footer shows the total, for example how many messages over how long, and when it stops.

| Measure type | Shapes |
| --- | --- |
| Numeric | **Random**, **Smooth**, **Wave**, **Ramp**, **Steps**, **Spikes**, **Constant**, **Off** |
| Boolean | **Mostly true (95%)**, **Toggle every 5 min**, **Random**, **Always true**, **Always false**, **Off** |
| Text | **Constant**, **Off** |

**Off** leaves the measure out of the messages. Pick at least one measure.

### While it runs

The simulation runs on IoT Breeze, so it **keeps running when you leave the page**. A banner at the top of the thing page shows **Simulating**, the interval, the time left and how many messages were sent.

| Button | What it does |
| --- | --- |
| **+15 min** | Runs 15 minutes longer. |
| **Edit…** | Opens the form again. Use **Restart simulation** to apply changes. |
| **Stop** | Ends the simulation. |

If sending fails, the banner says **Simulation stopped: the data could not be sent**. Select **Dismiss** to clear it.

:::info Simulated data is marked
Messages from a simulation carry a tag that marks them as simulated. They are stored and appear in charts like real data, so use a test thing if you do not want them in the history of a real device.
:::
