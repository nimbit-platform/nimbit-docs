The User Manual explains IoT Breeze page by page, grouped by what you want to get done. New to IoT Breeze? Start with [Get started](../get-started/index.mdx): it takes you from a first device to a first dashboard in about 30 minutes.

| Track | What you do there | Menu |
| --- | --- | --- |
| [Devices and data](./onboarding/index.mdx) | Model your devices, register them, connect them and shape their data. | Settings › Onboarding |
| [Dashboards](./dashboards/index.mdx) | Build dashboards, pick widgets, draw floor plans with Canvas. | Monitoring › Dashboards, Canvas |
| [Monitoring and alerts](./monitoring/index.mdx) | Watch things, maps and telemetry; handle events and incidents; decide who gets told. | Monitoring, Settings › Configuration |
| [Automation and reports](./automation/index.mdx) | React to data with rules and actions; send scheduled reports. | Settings › Automation |
| [Knowledge and Ask Nimble](./knowledge/index.mdx) | Describe sites, buildings and assets, and ask questions about your data in plain words. | Knowledge, Settings › Knowledge setup |
| [Administration](./administration/index.mdx) | Manage users, groups, roles, API keys, gateways, files and tenant settings. | Administration |

Select **?** in the header to open help for the page you're on. It links to the matching page in this manual and starts guided tours.
