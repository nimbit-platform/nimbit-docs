# Tenant Settings

Manage your tenant's appearance, technical configurations and system statistics. The tenant configuration is organized into four main areas, each accessible through dedicated pages:

## [General Settings](/docs/tenant-configuration/general)

Configure basic tenant information, branding assets and regional settings.

- System identifiers and custom naming
- Timezone and language preferences
- Logo, favicon and cover image uploads

[Go to General Settings →](/docs/tenant-configuration/general)

---

## [Theme Customization](/docs/tenant-configuration/theme)

Create a unique visual identity for your tenant with comprehensive theming controls.

- Light and dark mode customization
- Color schemes: base, forms, charts and sidebar
- Layout properties and spacing
- Shadow and elevation settings

[Go to Theme Settings →](/docs/tenant-configuration/theme)

---

## [Email Configuration](/docs/tenant-configuration/email)

Set up SMTP for outgoing email notifications and communications.

- SMTP server connection details
- Email authentication credentials
- Test email functionality

[Go to Email Settings →](/docs/tenant-configuration/email)

---

## [Statistics Dashboard](/docs/tenant-configuration/statistics)

Monitor your tenant's data usage and growth metrics over time.

- Current row count and storage usage
- Historical data trends (last 30 days)
- Database compression insights

[Go to Statistics →](/docs/tenant-configuration/statistics)
