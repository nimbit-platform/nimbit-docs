Use the telemetry explorer when you want to look back: how did a measure behave last week, and how do two things compare? You pick things and measures, IoT Breeze draws them, and you can save the result as a **query**.

For a live view of one thing, use its [thing page](./thing-page.mdx). For charts that stay on screen for everyone, build a [dashboard](../dashboards/index.mdx).

## Saved queries

**Monitoring › Telemetry** lists the saved queries you may see.

| Column | Shows |
| --- | --- |
| **Name** | The query name |
| **Access** | `Tenant` (everyone with access) or `User` (only you) |
| **Groups** | The groups the query is shared with |
| **Created** | The creation date |

Search with **Search queries**. Select a name to open the query. Select **Create query** to start a new one. With no queries yet you see **Create your first query**.

## Chart a measure

1. Select **Create query**. The explorer opens with one empty chart.
2. In the first row, choose a **Thing type**, a **Thing** and a **Measure**. Each field depends on the one before.
3. Choose an **Aggregation**: `raw`, `avg`, `min`, `max`, `sum`, `count`, `first` or `last`. Raw shows every reading. The others combine readings into buckets.
4. Select **Run**. The chart draws.
5. Set the **time range** at the top. The default is the last hour. Use the arrows to move the window.

If a row is incomplete, the explorer marks the missing field when you run. When you change a query after running it, the button reads **Run — chart is outdated**.

## Compare and customise

- **Add Query** (the plus in a chart) adds another row to the same chart. Use it to compare two things or two measures.
- **Add Chart** (top right) adds another chart below.
- The **Bucket size** at the top sets how much data one point covers. **auto** picks a size from the time range. A chart can override it. Zooming into the chart increases the resolution; the explorer shows the zoom resolution.
- In a row, the style button sets the **Chart type** (**Line**, **Area**, **Bar** or **Scatter**), the **Line style** and the **Series color**.
- **Custom time range** in a chart gives it its own time range. Without it the chart uses the global time range and says **Using global time range**.
- The chart title field (**Untitled Chart**) names the chart. Use the icons to collapse, duplicate, open settings for or remove it.

### Take the data with you

In a chart, open **More** and choose **Fullscreen**, **Download CSV** or **Save as SVG**.

## Save and share a query

1. Select **Save**.
2. Enter a **Name** in **Query name**.
3. Choose the **Access Type**: **Tenant** for everyone who may open telemetry, or **Personal** for only you.
4. For tenant access, you can add **Group**s. {/* TODO(product): Does adding groups to a Tenant query limit who can open it to members of those groups? The code stores the groups on the query, but no access rule for saved queries was found, unlike dashboards. */}
5. Save. The query appears in the list.

When you reopen a saved query, **Save** overwrites it. **Config** reopens the name and access settings. **Delete** removes the query.

To share without saving, select **Share** and copy the link. The whole chart setup is in the link. The recipient needs access to the same things.

:::tip Start from a measure
On a thing page, open **Schema**, select a measure and choose **Open in Explore**. The explorer opens already filled in for that measure and the last day.
:::
