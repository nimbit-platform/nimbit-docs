# User Manual

Welcome to the NimBit User Manual. This section helps operators, admins, and project teams set up and run IoTBreeze in day-to-day operations.

## Introduction

IoTBreeze is designed to turn machine and asset data into concrete operational value. The documentation in this area focuses on practical implementation: onboarding devices, structuring data, building dashboards, and automating reactions to events.

## What You Can Do with IoTBreeze

- Integrate heterogeneous assets and data sources into one platform.
- Visualize live and historical telemetry with dashboards and widgets.
- Automate actions, notifications, and backend workflows.
- Apply ETL and AI capabilities to improve decisions and reduce downtime.
