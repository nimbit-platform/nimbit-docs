**Files** is the file explorer of your tenant. Dashboards, reports and things show files from here, for example images, documents and attachments.

:::info What you need
Permission to create, update or delete files. The built-in **Admin**, **Manager** and **Modeler** roles have it. The **Viewer** role only sees files where a dashboard, report or thing shows them.
:::

## Browse

Open **Administration › Files**. Switch between **List view** and **Grid view**. Use **Search files** to find a file by name. Each row shows **Name**, **Size**, **Type**, **Modified** and **Tags**.

Two folders are special.

| Folder | What it is |
| --- | --- |
| **Things** and **Thing types** | One folder per thing or thing type. You cannot create, rename, move or delete these folders here. Put files inside them. |
| `_internal_` | Files that other pages of the app use. |

## Upload and organise

| Task | How |
| --- | --- |
| Upload | Select **Upload**, or drag and drop files into the explorer. The dialog shows the **Max file size**. |
| New folder | Select **New Folder** and enter a name. Inside a folder use **New Subfolder**. |
| Rename, cut, copy, paste | Use the actions on a file or folder. Cut or copy, open the target folder, then **Paste into folder**. |
| Download, preview | **Download**, or **Preview** for supported file types. |
| Delete | **Delete**, then confirm. This cannot be undone. |

## Tags

Select **Tag** on a file to add tags. Tags help you find and filter files.

## Share a link

1. Select **Share link** on a file.
2. Choose how long the link is valid: **Expires in** hours or days.
3. Select **Generate link**, then **Copy link**.

Anyone with the link can open the file until it expires.

## Search index

Files can be used to answer questions in **Ask Nimble**. The **Search index** setting on a file controls this: **Answers can cite this file** or **Not used when answering questions**. Files in a record's own folder are on by default. The setting is in a file's details panel. Without permission to change files it is shown read-only.

## Delete with care

Before you delete files from a folder that a dashboard's file list widget shows, IoT Breeze warns you with **Folder used by widgets** and lists the dashboards. After the deletion those widgets show no files or fewer files.

Deleting from `_internal_` asks for a second confirmation (**Delete anyway**) because other pages may break.
