An action is a command you define once and fire when you need it. For example **Restart pump** sends a message to a device, or calls a web address. People fire actions from the thing page. They can also add them to dashboards, and every run is logged.

:::info Actions are not rule actions
The **Actions** tab on a thing type or thing is about commands for devices. The steps a rule runs (**Email**, **Notification channel** and so on) are separate. You build those in [Rule Designer](./rule-designer.mdx).
:::

## Where actions live

| Level | Where | Effect |
| --- | --- | --- |
| Thing type | Thing type page, **Actions** tab | Available to every thing of that type. On a thing they show as **Inherited**. |
| Thing | Thing page, **Actions** tab | Only for that thing. |

Open [**Settings › Onboarding › Thing Types**](../onboarding/thing-types.mdx) or [**Settings › Onboarding › Things**](../onboarding/things.mdx), open one, then go to **Actions**.

## Create an action

1. On the **Actions** tab, select **Create action**.
2. Choose the action type and fill in the form.
3. Save.

| Type | Use it to |
| --- | --- |
| **MQTT message** | Publish a message to the device's command topic. Works for devices connected with the provider **Nimbit**. |
| **Webhook** | Call an HTTP address of another system. |
| **Azure cloud-to-device** | Send a message to a device registered with the provider type Azure. |

### MQTT message

| Field | Meaning |
| --- | --- |
| **Sub-topic** | Optional. Appended to the device's command topic `iot/tenant/<tenant>/device/<device>/cmd/`. Use letters, digits, `_` or `-`, separated by `/`. |
| **Payload format** | **JSON** or **Text**. With JSON, the result must be valid JSON. |
| **Payload** | The message. Placeholders are replaced when the command is sent. Only plain placeholders work, no sections or partials. |

### Webhook

The form has three steps: **Request**, **Authorization** and **Overview**.

| Field | Meaning |
| --- | --- |
| **Name** | Shown in lists and dashboards. |
| **Method** | `GET`, `POST`, `PUT`, `PATCH` or `DELETE`. |
| **URL** | The address to call. |
| **Body** | The request body. Not for `GET`. |
| **Headers** | Extra HTTP headers. |

Under **Authorization** you choose how the call signs in: no authentication, Basic (username and password), a Bearer token, credentials as query parameters, or OAuth 2.0. The **Overview** step lets you try the request before you save.

### Azure cloud-to-device

The message is sent on the `/devicebound` topic, which the connected device reads.

| Field | Meaning |
| --- | --- |
| **Name** | Shown in lists. |
| **Description** | Optional. |
| **Is toggle action** | Makes an on/off action. See below. |
| **Payload** | The message. With a toggle action it is called **Payload on**. Placeholders are replaced when the command is sent. |
| **Payload off** | The message for off. Only for toggle actions. |

### On/off actions

Turn on **Is toggle action** to make an on/off action. You give it an on payload and an off payload (**Payload off**). On a thing page, the action shows whether the thing reports it as on or off, based on the latest reading of its measure. The thing needs to have reported that measure at least once. Only Azure cloud-to-device actions offer this option. The MQTT message form has no **Is toggle action** switch.

## Fire an action

- **On a thing page:** select the action's button on the **Actions** tab. On/off actions show **Turn on** or **Turn off**.
- **On a thing type page:** select **Fire**. Because a type has many things, a dialog asks which **Thing** to send it to.

A message confirms delivery, for example that the command was delivered on a topic. If the button is disabled, your role may not run actions, or the action is inactive. An inactive action has **Active** turned off.

## Check what ran

Switch from **Actions** to **Log** (the pill control above the list). Every run is listed with **When**, its status and where it came from: a dashboard, a rule or the API.

## Edit or delete

Use the pencil and bin icons on a row. Deleting cannot be undone. Actions marked **Inherited** come from the thing type. Change them there.
