Node-RED is a separate flow editor that your platform team can connect to IoT Breeze. You wire blocks together to move data, call other systems and run logic that goes beyond a rule.

:::info Not available everywhere
**Node Red** only appears in the **Automation** menu if your administrator has set a Node-RED address for IoT Breeze, and your role may update rules. If you don't see it, ask your administrator.
:::

## Open Node-RED

1. Open **Automation** in the left menu.
2. Select **Node Red**. It opens in a new browser tab.

## Rule Designer or Node-RED?

Start with [Rule Designer](./rule-designer.mdx). It is built into IoT Breeze, has versions and a draft, and needs no code.

| You want to | Use |
| --- | --- |
| Send an email, notification or webhook when a measure crosses a limit | Rule Designer |
| Require a value to hold for a time, or fire only once | Rule Designer (triggers) |
| Create an event or update a measure | Rule Designer |
| Reshape or enrich data with your own logic before it is used | Node-RED |
| Connect a system that needs a custom protocol or a sequence of calls | Node-RED |
| Build something a non-technical colleague must be able to maintain | Rule Designer |
