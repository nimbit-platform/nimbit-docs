The **Automation** menu holds everything that works without you watching a dashboard. You find it in the left menu, under **Automation**. You only see the entries your role may use.

| Menu entry | What it is for |
| --- | --- |
| **Rule Designer** | Watch values from your things and react when a condition is met, for example send an email. |
| **Reports** | Build a PDF from widgets and send it on a schedule. |
| **Node Red** | Open Node-RED for flows that Rule Designer cannot express. Shown only if your administrator set it up. |

## Read in this order

1. [Rule Designer](./rule-designer.mdx): build a rule, test it, turn it on. It ends with a worked example: email me when the temperature is above 25 °C.
2. [Actions](./actions.mdx): commands you can send to a device, from a thing page or a dashboard.
3. [Reports](./reports.mdx): create a report, set its schedule and choose who receives it.
4. [Node-RED](./node-red.mdx): when to use it instead of Rule Designer.

## Before you start

Rules usually need two things from other parts of the app:

- Things that send data. See [First device to first dashboard](../../get-started/first-device.mdx).
- A way to reach people. To send to Slack, Teams, a webhook or ntfy, create a channel under **Configuration › Notification Channels** {/* TODO: link */}. To send email, you need a mail server set up for your tenant.

:::tip Guided tour
In the app, the guide **Get told when it matters** walks you through event types, notification channels, rules and reports. Open it from the **?** help drawer.
:::
