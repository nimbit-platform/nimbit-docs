The events of the dashboard: on a tenant-wide dashboard every event of the tenant, otherwise the events of its things. One row per event, newest first.

This widget needs no thing and is offered on any dashboard.

## Settings

Add the widget with **Add widget**, in the group **Events and rules**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Event types** | One or more types to show. Empty means all. |
| **Time range** | Follows the dashboard unless you override it. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

Chips filter by severity and show counts. **Open event explorer** opens the events page with the same filter.
