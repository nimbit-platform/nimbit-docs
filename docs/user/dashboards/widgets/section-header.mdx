Names a group of widgets, with an optional description and link, above a thin divider. It has no card.

This widget needs no thing and is offered on any dashboard.

## Settings

Add the widget with **Add widget**, in the group **Layout and content**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Title** | Required. |
| **Description** | One line under the title. |
| **Link text, Link target** | A link on the right. The target is an app page starting with `/` or a web address starting with `https://`. |
| **Space above** | S, M or L. |
| **Divider** | The thin line under the header. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

Title, description and link text can be translated. Make it narrower to head one column.
