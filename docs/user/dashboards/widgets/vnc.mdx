## Settings

Add the widget with **Add widget**, in the group **Layout and content**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **VNC server** | The server to show. Required. |
| **Quality** | **Server Default**, **Low**, **Balanced** or **High**. |
| **Auto connect** | Connect when the dashboard opens. |
| **Show toolbar** | Show the connection toolbar. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

Only offered when VNC is enabled for your deployment. Whether you can type into the screen is set on the VNC server, not on the widget. Manage VNC servers under **Settings › Configuration › VNC Servers**.
