## Settings

Add the widget with **Add widget**, in the group **Layout and content**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **URL** | The full address, for example `https://example.com`. Required. |
| **Appearance** | Border colour. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

The target site must allow embedding. Some sites block it with `X-Frame-Options` or a content security policy.
