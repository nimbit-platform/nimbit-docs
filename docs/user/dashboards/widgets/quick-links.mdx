## Settings

Add the widget with **Add widget**, in the group **Layout and content**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Title** | Shown above the links. |
| **Links** | Up to twelve, dragged into order. Pick built-in links (Documentation, Things, Rules, Dashboards, Events, API keys, Users and groups, Contact support) or add a custom link. |
| **Custom link** | A title, an optional description, and a target: an app page (`/…`), a web address (`https://…`) or an email address (`mailto:…`). |
| **Reset to default** | Brings back the default set. |
| **Card** | Background and border colours. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.
