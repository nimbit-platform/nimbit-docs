The product's newest announcements. New entries carry a **New** badge; **Mark as read** clears them for you.

This widget is about the whole tenant. It is offered on Home and other tenant-wide dashboards, not on a dashboard about a thing.

## Settings

Add the widget with **Add widget**, in the group **Layout and content**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Title** | Shown above the list. |
| **Entries** | 3, 5 or 10 announcements. |
| **Card** | Background and border colours. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

What you mark as read is yours. The announcements are the same in every tenant.
