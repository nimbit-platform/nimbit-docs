Measures over time. Pick a layout: **Line**, **Area**, **Bar**, **Scatter** or **Combination** (bars and lines on one chart). You can change the layout later in the widget's settings.

This widget reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own. See [Smart dashboards](../smart-dashboards.mdx#follow-or-pin).

## Settings

Add the widget with **Add widget**, in the group **Charts**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Measures** | One or more rows. Each has a thing, aggregation, chart type, line style, stacking, Y-axis group, colour and alias. |
| **Time range** | The period and the bucket size. Follows the dashboard unless you override it. |
| **Thresholds** | Horizontal lines with colour and label. |
| **Display** | Chart or table. |
| **Markers, Zoomable, Compact Y-axis** | Show points, allow zoom and pan, shorten large axis values. |
| **Legend placement** | Bottom, right or hidden. |
| **Y-axis range** | Minimum and maximum. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.
