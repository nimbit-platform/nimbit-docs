Every thing by connection state, as one tile per thing type or group with how many are online and a bar of connected, offline and never connected things.

This widget is about the whole tenant. It is offered on Home and other tenant-wide dashboards, not on a dashboard about a thing.

## Settings

Add the widget with **Add widget**, in the group **Connectivity**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Title** | Shown above the tiles. |
| **Tiles by** | **Thing type** or **Group**. A thing in several groups counts in each. |
| **Card** | Background and border colours. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.

Tiles with things offline come first. With up to 100 things, a thing type tile shows each thing as a small square. The state refreshes every minute.
