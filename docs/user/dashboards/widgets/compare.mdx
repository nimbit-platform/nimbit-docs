Two values side by side, with the difference. Also useful for a KPI such as an average, total or peak over a period.

This widget reads a thing. On a Smart dashboard it follows the selected thing or is pinned to a thing of its own. See [Smart dashboards](../smart-dashboards.mdx#follow-or-pin).

## Settings

Add the widget with **Add widget**, in the group **Values**. Select **Help** in the setup to read about its settings in the app.

| Setting | What it does |
| --- | --- |
| **Measure** | One measure with its aggregation, icon and icon colour. |
| **Time range** | The period the value covers. |
| **Compact number** | Shorten large values, for example 1.2 k. |
| **Alignment, Text size** | How the value is drawn. |

Every widget also has a **Title** and, where it shows a card, **Appearance** settings for colours. Time-based widgets follow the dashboard's [time range](../time-range-and-filters.mdx) unless you set their own.
