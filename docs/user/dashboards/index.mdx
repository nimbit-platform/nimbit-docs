A dashboard is a page of widgets. Each widget answers one question: how warm is it now, how did a value move today, which things are offline. This section shows how to build dashboards, set their time range, share them and put them in front of the right people.

Open them under **Monitoring › Dashboards**.

## Key ideas

**Smart dashboard.** The dashboard you create today. It matches things by the interfaces their thing types implement, so one dashboard serves every fitting thing, now and later. Older dashboard kinds (thing dashboards, thing type dashboards, collections) still exist; you open them from the places they belong to.

**Follow or pin.** A widget either *follows* the thing selected at the top of the dashboard, or is *pinned* to a thing of its own. One dashboard can hold both.

**Edit mode.** Changes to a dashboard stay a draft until you save. Nobody else sees them before.

:::tip Guided help
The app has a guide, **Build dashboards**, with chapters for reading, building and assigning dashboards. Open it from the **?** help drawer, or from the empty dashboards list.
:::
