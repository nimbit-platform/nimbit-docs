A canvas is a drawing of your plant or machine with live values on it. You place values, gauges, charts, shapes and process symbols, and bind them to things. Viewers see the values update as devices report.

Open canvases under **Monitoring › Canvas**.

:::info Who sees this menu entry
**Canvas** appears for roles that may create, edit or delete canvases. A role that may only read canvases sees them embedded in dashboards.
:::

## Kinds of canvas

| Kind | Use it for |
| --- | --- |
| **Monitoring** | Arranging values and charts. |
| **P&ID** | Following a process drawing, with pumps, valves and tanks. |
| **Managed by Nimbit** | Canvases that come from a Nimbit template and receive updates. |

The filter chips above the list narrow it by kind. Switch between cards and table: cards show a preview and alarms, the table is for sorting and for deleting several canvases at once.

## Create a canvas

1. Open **Monitoring › Canvas**.
2. Select **Create new canvas**. The **New canvas** dialog opens.
3. Enter a name.
4. Select the interfaces the canvas reads. With interfaces, viewers pick a context thing, and one canvas serves every matching thing. Without them, every element binds to a fixed thing.
5. Under **Start from**, choose how to begin.

| Start | What you get |
| --- | --- |
| **Blank canvas** | Place values, gauges, shapes and symbols yourself. |
| **From image** | Any picture, such as a floor plan or machine photo. Place live elements on it. |
| **From P&ID drawing** | Upload a PDF or image. Its tags are matched to things for you. (Beta) |
| **From a template** | Start from a Nimbit canvas. Add it **managed by Nimbit** (kept up to date) or as **a copy to change freely**. |

## Read a canvas

Open a canvas to see it live.

- **Alarms.** When a value is in alarm or has gone stale, a chip in the header lists it. Select it to jump to the next one.
- **Which thing.** On a canvas built on interfaces, pick the thing to show in the header. The link you share keeps the choice.
- **Live or history.** Pick a time range to see how values looked then. A live range brings back current values.
- **Explore.** Drag to pan. Scroll or use the zoom buttons to zoom. Click an element for its details.
- **Operate.** Buttons, valves and setpoints that you may operate send commands to devices, usually after you confirm. Operation pauses while a past range is shown.
