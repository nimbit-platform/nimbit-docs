In this page you create a dashboard, fill it with widgets and decide who sees it. It takes about ten minutes.

:::info What you need
A role that may create and edit dashboards. If **New dashboard** is missing on the Dashboards page, your role may only read them.
:::

## 1. Create a dashboard

1. Open **Monitoring › Dashboards**.
2. Select **New dashboard**.
3. Answer **What should this dashboard show?**

| Choice | Use it when |
| --- | --- |
| **From interfaces** (recommended) | The dashboard should work for every thing that implements one or more interfaces, or a thing type. |
| **For one thing** | You build the dashboard for a single thing. Search and pick it, then select **Continue**. Its thing type becomes the interface and the thing the assignment. |

4. In the form that opens, fill in the fields.

| Field | What it does |
| --- | --- |
| **Dashboard name** | A name people recognise, such as `Hall 2 machines`. Required. |
| **Description** | One line on what the dashboard is for. |
| **Default dashboard** | Switch on to open this dashboard first where several are offered. |
| **Tenant dashboard** / **User dashboard** | Who can see it. See [Who can see a dashboard](#who-can-see-a-dashboard). |
| **Interfaces / thing types** | The interfaces the dashboard needs. Below the field, a preview counts how many things fit today. Leave it empty if every widget names its own thing. |
| **Hierarchy node** | Only if your tenant uses the [dashboard hierarchy](./hierarchy.mdx). |

5. Select **Save**.

## 2. Add widgets

A new dashboard is empty and shows **No widgets created yet**.

1. Select **Add widget**.
2. Pick a widget type. The groups are named by the question they answer, for example **Values** (*What does it read right now?*) or **Charts** (*How did it change?*). Search finds a widget by name or description.
3. Choose where its data comes from. See [follow or pin](./smart-dashboards.mdx#follow-or-pin).
4. Set it up. The preview updates as you change settings. **Help**, at the top, explains the widget and its settings.
5. Select **Add to dashboard**, or **Save** when you edit a widget.

Every widget type is listed in [Widgets](./widgets/index.mdx).

## 3. Edit, arrange and save

Changes are a draft until you save.

1. On an existing dashboard, select **Edit**. The dashboard goes into edit mode and shows **Add widget**.
2. Drag a widget to move it and drag its edge to resize it.
3. Open a widget's menu to change or remove it.
4. Use **Undo** and **Redo** if you slip. They work on the draft.
5. Select **Save**.

Other tools in edit mode:

| Tool | What it does |
| --- | --- |
| **Arrange** | **Fill rows** closes gaps in rows. **Keep sizes** repacks the widgets without resizing. **Tidy up (resizes widgets)** lines everything up and may resize widgets. |
| **Import Widget** | Copy a widget from another dashboard of the same type. |
| **Discard** | Throws away every change since the last save. This cannot be undone. A prompt asks **Discard your changes?** first. Select **Keep editing** to stay. |

The toggle button changes with your work: it reads **Edit** when the dashboard is locked, **Save** when you have unsaved changes and **Done** when you have none.

:::warning Leaving with unsaved changes
If you navigate away with unsaved changes, the app warns you that all changes will be lost.
:::

If you changed the time range while editing, **Save** asks **Save this time range too?** Choose **Save with range** to keep it as the dashboard's default, or **Dashboard only**. More in [Time range and data source](./time-range-and-filters.mdx).

- **Duplicate dashboard**
- **Delete dashboard**

## 5. Show a dashboard on Home

Home is the page people land on. A Smart dashboard that needs no thing, for example one with only pinned widgets or tenant statistics, can go there.

1. Open the dashboard.
2. Select **Show on Home** in the header.
3. Tick **For everyone** to put it on everyone's Home, or **Just for me** for your own.

Each click saves at once. The button then reads **On Home for everyone** or **On my Home**. Clear the tick to remove the dashboard from Home.

**For everyone** is offered only for a tenant dashboard. Other members cannot open a private dashboard.

## Who can see a dashboard

Choose it when you create the dashboard.

| Option | Who sees it |
| --- | --- |
| **Tenant dashboard** | Everyone in your tenant who may read dashboards. |
| **User dashboard** | Only you. |

Beyond that, a dashboard shows up on things through its [assignment](./smart-dashboards.mdx#assign-the-dashboard).
